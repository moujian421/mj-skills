## 1. 副图版式：上标题、中商品、下证据

副图都是竖图 1200×1500（4:5），不是正方形。骨架基本固定：

```
┌────────────────────────┐
│ [品牌角标]  主标题（居中，1–2 行） │  顶部约 15%
│        副标题（可选，一行小字）     │
├────────────────────────┤
│                        │
│    商品 / 场景（占 50–65%）       │
│                        │
├────────────────────────┤
│  数据区：大数字 + 小单位，或 2–4 个白色圆角卡  │  底部 15–25%
│  脚注小字（测试条件、配件不含）               │
└────────────────────────┘
```

- **标题位置**：几乎都是顶部居中。例外是生活场景图，标题仍在顶部，但压在照片上（充电宝 g04「Sleek and Powerful With 25,000mAh」白字压在机舱照片上）。
- **副标题**：多数图没有副标题，有就是一行解释性小字，例如充电宝 g05「Power Up Four Devices at Once」、g04「Flight-Ready Power for Long Adventures」。
- **底部元素**三种常见做法：
  - 大数字结果：充电宝 g02 底部「Charge to 50%」+ 四台设备各自分钟数（33 Min / 21 Min / 25 Min / 28 Min）。
  - 分组白卡：充电头 g06 用两张白卡分「1-Port Output」「2-Port Output」；充电头 g08、充电宝 g05 用白卡分「适用设备 / 不适用设备」。
  - 一行数字：充电宝 g04 底部「1.3 Charges MacBook Air / 1.4 iPad Pro / 4.5 iPhone 16 / 4.7 Samsung S23」。
- **脚注**：凡有数据就有一行灰色小字，例如「Data based on internal lab testing」「USB-C to Lightning Cable Not Included」。放在最底部，不抢视线。
- **品牌角标**：左上角蓝色「ANKER The World's NO.1 Mobile Charging Brand」小旗，只出现在第 2 张（第一张副图）和 A+ 第一块。

## 2. 主标题写法和强调方式

- 标题是**直白的功能句或参数句**，不是口号：「Charge Two Devices Simultaneously」「Two 5 ft USB-C to USB-C Cables Included」「3 USB-C Ports with 100W Max Power Each」「Real-Time Smart Display」。
- 字数：多在 3–7 个单词，最长约 8 个单词，最多 2 行。
- 数字常直接进标题：「Charge Your iPhone 3X* Faster with 20W Max」「Sleek and Powerful With 25,000mAh」。
- **强调方式靠字号和颜色，不靠描边、渐变、倾斜**：标题整句一个颜色（老图用 Anker 蓝，新图用深灰/黑），没有"半句蓝半句白"的双色标题。重点数字放到画面中部或底部单独放大，而不是在标题里变色。
- 新图有两行对仗的写法：充电宝 g07「Crafted For Power. / Designed With Style.」、g08「Compact Build. / Full Functionality.」，但只用在外观、结构这类不好量化的图上。

## 3. 配色和底色

- **底色是浅色**：白、浅灰（约 #F2F3F5）、极浅蓝灰渐变。三款 26 张副图里只有 1 张深色底（充电宝 g04，是真实机舱照片，不是纯色深底）。
- **强调色只有一个**：Anker 青蓝（约 #00A8E8 一类），用在标题（老图）、数字（「21 oz」「20W Max」）、图标线条、品牌角标。
- 功能色只用在电量示意：电池图标里**绿色**表示充满（数据线 g02、充电头 g04 的「0% → 30 Minutes → 55%」），红色只出现在「×」禁止标记上。
- 商品本身是黑、银、白，背景浅色正好衬出商品，不需要给商品加光效描边。
- 唯一"科技感特效"是充电头 g07 安全保护：透视电路板 + 浅蓝盾牌光，底色仍然是浅色。

## 4. 数字和参数怎么可视化

- **"大数字 + 小单位/小说明"** 是最常用的单位：「5,000 Bend Lifespan」（数据线 g03）、「20,000 Retractions」「20,000 Bends」「21 oz」（充电宝 g03）。数字字号约为说明字的 3–4 倍。
- **前后对比的电量条**：左边空电池「0%」→ 箭头 + 「30 Minutes」→ 右边绿色电池「55%」/「54%」。数据线和充电头都用这一招，读图不需要看文字。
- **端口分配图**：充电头 g06 / A+ a03 用线框画充电头正面，每个口引线标「20W Max」「18W Max」「7.5W Max Each」，单口 / 双口分两块。
- **屏幕信息拆解**：充电宝 g06 把屏幕上的三种显示（温度、各口瓦数、电池健康）做成三个小黑卡，下面放屏幕特写，再用细引线标「Battery Input」「Remaining Battery」。
- **尺寸**：不画尺寸线，或只画细线 + 小字（充电宝 g07 手握图下写「21 oz / 6.18 × 2.12 × 1.93 in」；A+ a08 用天平对比一瓶水表示重量）。
- **结构图**：数据线 g05「Premium Engineering」剖面图，每层一条细引线标材料名（22-AWG Wiring / Aluminum Shielding / Nylon Shielding）；充电宝 g08 爆炸图只标题、无引线，配脚注说明图来源。
- **兼容性**：白色圆角卡分组，每格「设备小图 + 型号小字」，单独留一格「Reminder」写不含的线材，用绿勾 / 红叉。

## 5. 文字量和文案节奏

- 每张副图一个点：标题 1 句 + 最多 1 组数据。数据线全套 9 张副图中有 3 张完全没有标题（g06 编织纹特写、g07 卧室场景只放「6 ft」小圆标、g08 平铺）。
- 文案节奏是"一张有字、一张少字"交替：参数图后面常接一张纯场景或纯特写，眼睛有休息。
- 小字说明多但字号小、灰色，不和标题竞争（脚注、Reminder、测试条件）。
- 不用感叹号，不用「ULTIMATE」「BEST」这类大词；最"夸"的一句是品牌角标「The World's NO.1」，并配有出处脚注。

## 6. 主图做法

- 三款主图都是**纯白底、商品照片、没有任何文字、图标或徽章**。
- 多件装直接把件数摆出来：数据线主图 2 条交叉排布，充电头主图 2 个充电头 + 2 条线上下排。
- 角度：充电宝主图斜 3/4 角度，屏幕亮着显示「100」，自带线自然垂下，比正面平拍更有体积感。
- 颜色变体用单独的副图（数据线 g09/g10 红色、充电头 g09/g10 绿/白、充电宝 g09 银色），和主图同构图同角度，只换颜色。
- 主图没有文字徽章。Anker「NO.1」蓝色角标放在**第一张副图**和 A+ 上，不在主图上。

## 7. A+ 模块顺序和每块的作用

A+ 全部是 1464×600 横幅（新图 2928×1200 高清），一块讲一件事。顺序大致如下：

| 顺序 | 作用 | 实际例子 |
|---|---|---|
| 1 | 品牌 + 商品开场：品牌角标、商品名、一句话卖点、奖项 | 充电宝 a01「Anker Power Bank / Charge in a Flash, Share in a Dash」+ iF、红点奖标；充电头 a01「Efficient Dual-Port Charging」 |
| 2 | 产品大图（可无字），和第 1 块上下接成一张长图 | 充电宝 a02 两色产品照，只有一行脚注 |
| 3 | 卖点总览：中间商品，两边 4–6 张白卡各一个卖点 | 充电宝 a03「100W」「Smart Display」「25,000mAh」「Flight-Approved」 |
| 4–7 | 每个核心卖点一块，场景照 + 左侧标题 + 白卡数据 | 充电宝 a04–a07：不同人数、不同场景对应不同输出组合（100W / 165W / 130W） |
| 8–12 | 参数细节：速度、回充、屏幕、安全、重量、线材寿命 | 充电宝 a09「Unlock Faster Single Output with 100W Max」、a12「ActiveShield 2.0」、充电头 a03 端口分配 |
| 后段 | 兼容性白卡 | 三款都有「Universal Compatibility / Universally Compatible」 |
| 收尾 | 生活方式场景，只有一句标题 | 充电宝 a14–a16「Your Travel Companion…」「Keep Charged on Every Adventure」 |
| 最后 | 说明类：容量去向、计算公式 | 充电宝 a17「Where Your 25,000mAh (90Wh) Capacity Goes」，用文字解释实际可用容量 |
| 品牌故事 | 品牌介绍 + 产品线卡片 | 共用的蓝底「The World's NO.1」+ 黑底产品线卡 |

- 老款 A+ 用"左图右文"标准模块：左侧圆角图片、右侧一个标题 + 两行描述（数据线 a03–a05「High-Speed Compatible」「Universal Compatibility」「Hard-Wearing Exterior」）。
- 新款 A+ 场景照占满整块，标题和白色数据卡直接压在照片左侧的空处。
- 同一卖点在副图和 A+ 都会出现，但 A+ 换横版构图、换场景，不直接复用副图。
- 充电宝 a18/a19 是自家型号对比（100W 蓝框 / 140W 黑框），不是和别家比。

## 8. 和 REDTIGER / WOLFBOX "深色底 + 强调色"风格的区别

| 方面 | Anker | REDTIGER / WOLFBOX |
|---|---|---|
| 底色 | 浅色（白 / 浅灰 / 浅蓝灰），深色只出现在真实场景照里 | 深色纯色或暗场景为主 |
| 标题 | 单色、直白功能句，强调靠字号 | 常用双色标题、强调词换色 |
| 强调色 | 一个品牌蓝 + 电量绿，用得少 | 强调色用量多，配光效、描边 |
| 数据呈现 | 大数字 + 小说明、白色圆角卡、电量条 | 证据卡、图标排、参数条，信息更密 |
| 文字量 | 少，常有无标题的纯场景 / 特写图 | 每张都有标题和底部证据区 |
| 气质 | 干净、像消费电子说明书 | 有力、技术感、偏汽车 / 工具 |
| 适合 | 外观本身好看、颜色浅、走日常 / 办公 / 旅行场景的商品 | 深色机身、户外 / 车载 / 工具类商品 |

两种不是谁好谁坏，按商品颜色和使用场景选。

## 可以怎么借鉴（按需挑选）

- 可以把副图做成竖版 4:5（1200×1500），比正方形多出的高度给标题和底部数据区。
- 可以考虑浅灰底 + 单一品牌强调色，标题整句一个颜色，重点数字单独放大，而不是在标题里做双色。
- 可以把"充电前后对比"类卖点做成"空状态 → 时间 → 结果"三段式（例如 0% → 30 Minutes → 55%），让人不看字也能懂。
- 可以用"大数字 + 小说明"表达寿命、重量、次数，数字约为说明字 3–4 倍大。
- 可以考虑在参数图之间插一张无标题或只有一个小标签的场景 / 质感特写，降低整套图的文字密度。
- 兼容性可以用白色圆角卡分组，单独一格写"不包含 / 不适用"，配绿勾红叉，减少差评。
- 凡是有数据的图，可以在底部加一行灰色小字脚注写测试条件。
- A+ 可以按"开场 → 卖点总览 → 逐个卖点场景 → 参数细节 → 兼容性 → 生活场景收尾"排；同一卖点在 A+ 换横版构图，不直接放大副图。
- 对比图如果要做，可以学充电宝 a10 的做法：只比泛称（「Other 65W Power Bank 26 Min」「Other 30W Power Bank 53 Min」），并注明测试依据；我方只比 Others，并且必须有实测或公开数据支撑。
- 多件装、多颜色，可以考虑主图直接摆出全部件数，颜色变体用同构图同角度的副图。
- 品牌角标、奖项标志只在有真实依据时考虑，且只放副图 / A+，主图不放。
