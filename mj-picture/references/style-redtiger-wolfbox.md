## 1. 副图版式：固定三段式

几乎每张副图都是同一个骨架，买家翻图时视线不用重新找：

```
┌────────────────────────┐
│   主标题（居中，双色）   │  顶部 10–15%
│   一行副标题（小、浅色） │
├────────────────────────┤
│                        │
│   主视觉：商品特写或场景 │  中部 55–65%
│   （商品是画面主角）     │
│                        │
├──────┬──────┬──────────┤
│ 证据卡│ 证据卡│ 证据卡   │  底部 20–25%：2–4 个圆角卡片或一排线性图标
└──────┴──────┴──────────┘
  小字脚注（限制条件、配件需另购）
```

- 主标题居中，在顶部，通常 2–4 个单词，一行放下，偶尔两行。
- 副标题紧贴主标题下方，一行，字号约为主标题的 40%，白色或浅灰（浅底时用深灰），讲好处或用法，如 “Capture sharp details in low light”、“3-Gear, with Brushless Motor”。
- 底部证据卡：圆角矩形，统一圆角和描边，每张卡一张小图 + 2–3 个单词标签，用来证明主视觉讲的卖点（如传感器 / 镜头 / HDR，或胶贴 / 支架 / 后摄安装位置）。
- 不是每张都有底部卡片：纯场景图、尺寸图只用上两段。

## 2. 主标题双色写法

主标题拆成两部分：**强调词用品牌色，其余用白色（深底）或黑色（浅底）**。

| 强调词（品牌色） | 其余（白/黑） |
|---|---|
| Super | Night Vision |
| Powerful | Wind Speed |
| 3.5H | Fast Charging |
| 4 Different | Nozzle |
| Easy Access | Easy Operation |
| Time-lapse | Parking Monitor |

规律：强调词是**数字、程度词或这款的差异点**，后半是功能名词。一个标题只强调一处。

写进需求表时：在「画面与构图」列写“主标题强调词：xxx（品牌色）”，例如 AH-GC1 副图 1 `360° Swivel Front Wheel` → 强调词 `360°`。

## 3. 配色

- 一个深色底 + 一个强调色贯穿全套：REDTIGER 是黑/深灰 + 红，WOLFBOX 是黑/炭灰 + 橙。
- 功能图多用深色底（夜景、黑色渐变、深灰面板）；安装、尺寸、电路这类“说明型”图用浅灰或浅蓝底，读起来更清楚。
- 强调色只用在：主标题强调词、关键数字、角标（Free、Too Bright、158°F）、进度条。大面积仍是深色和商品本色。
- 同一个演示道具贯穿全套：REDTIGER 一直用红色轿车，WOLFBOX 一直用橙色越野车。买家翻几张就记住了“这个品牌的图”。

## 4. 把数字变成画面

- **大数字**：`10x Faster`、`≈0.45lb`、`24H`、`110000 RPM`，数字字号比主标题还大或同级，单位缩小。
- **对比条**：5.8GHz vs 2.4GHz 下载速度、不同内存卡能录多久，用长短不一的横条。
- **分屏对比**：左右或上下分屏，标签 `F7NP | Others`、`Too Bright | Too Dark`、`158°F | -4°F`。对比对象写泛称 Others / common，不点名竞品。
- **尺寸图**：浅灰底 + 标线 + 参照物（WOLFBOX 把吹尘器叠在手机上，一眼看出多大）。

## 4.5 补充（MV24A、MF100）

- **步骤条**：应急启动电源 A+ 用三格横排实拍写操作步骤（`1. Attach the clamps → 2. Ensure the indicator is green → 3. Start the vehicle`），普通模式和 BOOST 模式各一块。
- **参数宫格**：一块深色宫格把主要参数各占一格（`160PSI MAX`、`24000mAh Power Bank`、`65W Fast Charge`、`One-Touch BOOST`），数字是最大的字。
- **一机多用**：`5-in-1 Versatile Jump Starter` 用“本体 = 打气 + 启动 + 照明 + 球类充气”的加法式排版。
- **同一卖点分场景做系列**：MF100 A+ 连续三块 `Wide Application PC Clean / Home Clean / Outdoor Use`，标题结构相同，只换场景词。
- **送礼场景**：`Gift for Car Owners`，两个人在皮卡旁递礼物，适合节日季。
- MF100 用浅灰底 + 橙色强调词，说明深色并不是 WOLFBOX 唯一的底色；浅灰更适合银灰色机身。

## 5. 文案节奏

- 文字很少：主标题 2–4 词，副标题一行，卡片标签 2–3 词。长解释放 A+ 或五点。
- 副标题讲好处或用法，不重复主标题。
- 限制条件用底部小字脚注写清：`Hardwire kit is needed`、`*Use 5V/2A power adapter only`、商标声明。既诚实，又不打断主画面。

## 6. 主图

- WOLFBOX：纯白底，商品 + 全部随货配件平铺，干净，可以学。
- REDTIGER 主图放了 STARVIS 2、WiFi 6、128GB 等文字徽章，突出核心参数。

## 7. A+ 结构

两家 A+ 顺序几乎一样：

1. **品牌横幅**（1464×625）：生活方式大场景 + 左上 Logo + 一句品牌口号。
2. **品牌信任 3–4 格**（362×453 竖卡）：销量 / 覆盖国家 / 评论数、奖项、媒体背书、售后政策。**只放有真实数据和证明的项**，没有就不做这一块。
3. **产品开场**：Logo + 产品名（型号用强调色）+ 一句定位，右侧商品大图。
4. **功能总览宫格**（bento）：一块大卡 + 4–6 块小卡，把所有卖点缩成一屏，买家看一屏就知道全貌。
5. **逐个功能模块**：左侧文字区（双色主标题 + 1–2 行说明 + 2–3 个线性图标），右侧大视觉；深色底贯穿。
6. **包装清单**（What's in the Box）：每个配件一个圆角白卡 + 名称，或商品 + 包装盒实拍旁列关键参数。
7. 可选收尾：用户分布地图、好评关键词等社会证明（同样要有真实数据）。

## 可以怎么借鉴（按需挑选）

- 适合的图可以在「画面与构图」写三段式各放什么、主标题强调词。
- 想让全套更统一时，可以在表头「通用要求」写底色、强调色、贯穿全套的演示道具（如同一位球友、同一个球包）。
- 有数字的卖点（档位、尺寸、重量、轮径、转向角度）可以考虑做成大数字或对比条。
- 对比图只比“普通款 / Others”，且必须是实物真实差异，有依据。
- 限制条件（不含球包、折叠需取下前轮等）用底部小字脚注写。
