## 品牌通用规律

- **浅色底为主**：白、浅灰、极浅蓝灰渐变；只有新款扩展坞（Revodok Pro）整套用深色底。
- **标题顶部居中、深灰黑色、整句一个颜色**，无描边、无倾斜。副标题是一行灰色小字解释。
- **强调色少**：品牌绿用在小标签（「UGREEN」胶囊、「3.5mm」「2RCA」标签）、百分比数字（「55%」「50%」）、引线端点小绿点；扩展坞用青色 / 紫色区分接口类型。
- **结构剖面图 + 细引线标材料**是线材、充电头都用的固定一张（「Tinned copper core」「Aluminum Foil」「Braid Shielding」）。
- **兼容性图**：白色圆角卡分组，每格设备小图 + 型号小字，三类都有，标题统一「Universal Compatibility」。
- **场景图常常一张拼三格**：Home / Travel / Office 或 Family Concert / Multimedia / Home Video，每格左下一个短标签。
- **限制说明直接写在图上**：A+ 灰色「note:」小字或红色 Note（扩展坞最多），例如「The usb c PD port only can charge the host device…」。
- **颜色变体**：放在最后一张副图，和主图同角度只换颜色（30W 粉色、65W 白色、Hub 银色）。
- **A+ 都是 1464×600 横幅**，结尾挂系列 / 品牌故事模块（Nexode Pro、Revodok 系列横幅，品牌 Logo + 「MORE FOR YOU」介绍）。

## 充电器（B0DG93MZCR、B0GDCPBYHF）

**副图尺寸**：竖图 1125×1500（3:4），和 Anker 一样不用正方形。

**副图顺序**
- 30W：主图 → 3-IN-1 多设备同充 → 30W Max 速度 → 体积（38% Smaller）→ GaN 芯片 → 兼容性 → Home/Travel/Office 三格场景 → 保护 → 正面接口特写（无字）→ 粉色变体。
- 65W Air：主图（头 + 随附线）→ 充电速度（30 分钟 55%）→ 体积（74% Smaller）→ 四色 → 随附线卖点 → 质感三连（Premium Feel）→ 夜间涓流充电 → 温控 → 兼容设备 → 白色变体。
- 共同顺序：**多口 / 速度 → 体积 → 技术（GaN）→ 兼容 → 场景 → 安全 → 颜色**。

**版式**：顶部居中标题 + 一行副标题，中间商品，底部或侧边放数据。保护、GaN、兼容性图用 3–4 个圆形线框图标 + 两行小字横排。

**标题写法**（实际文案）
- 参数句：「30W Max Fast Charge」+ 副标题「for Single USB-C Port」。
- 数字开头：「3-IN-1」+「Power for 3 devices at the same time」。
- 对仗句：「3X Gan Chips, 3X Power」「Four Colors. One Clean Look」。
- 短口号只用在开场：「Pocket Power that Packs a Punch」「Power that Keeps Its Cool」。

**配色**：浅蓝灰渐变底 + 深灰机身；新款 65W 用浅灰白 + 绿色百分比，夜间充电图是唯一暖色暗场景。

**数字可视化**
- 超大浅色水印数字放在商品后面：30W g03 / a01 的「30W MAX」灰色大字。
- 体积：「38%」「74%」大数字 + 「Smaller」小字，旁边放自家旧款或原装大充电器做参照，标尺寸「1.22×1.30×1.59 inches」。
- 充电速度：「30Mins MacBook Air ▬▬ 55%」进度条 + 绿色百分比，底部脚注「Data from UGREEN testing」。
- 端口分配：线框画充电头正面，按单口 / 双口 / 三口分三块，引线标「30W」「7.5W」「5W」（A+ a09–a11）。
- 温控、涓流：折线 + 三段卡片「0–20% / 20–80% / 80–100%」。

**场景和人物**：手持 / 放包、插墙插座连手机平板；人物只在三格场景和 A+ 大场景出现，自然光、居家办公氛围，商品放在画面下半部分。

**A+ 顺序**：开场（大字 30W MAX 或多色产品飞散 + 口号）→ 颜色 → 多口 / 速度 → 体积 → 保护 → GaN → 兼容 → 端口分配图 → Home/Travel/Office 整幅场景 → 自家功率档对比（「Pick Your Mini Cube」45W/65W/100W）→ 系列横幅。

**和其他大类的差别**：唯一用 3:4 竖图的大类；技术感渲染（GaN 芯片、透明外壳 NTC）最多；有质感特写（金属涂层、磨砂、纹理三格）。

## USB-C 扩展坞（B0BR3M8XHK、B0D1XSKZRJ）

**副图尺寸**：正方形 1500×1500。

**副图顺序**：主图 → 接口总览（「5-in-1 Connectivity」/「7-in-1」）→ PD 充电 → 数据传输 → HDMI 显示 → 体积 / 手持 → 兼容性 → 显示 / 传输场景重复一遍 → 颜色变体。接口总览固定是第一张副图。

**版式**
- 接口总览：商品正面或两面平放，**每个接口一根细引线 + 彩色接口小图标 + 名称 + 括号参数**「USB-A 3.0 (5Gbps)」「HDMI (4K@30Hz)」。
- 功能图：上方大标题，下方场景照；或场景照占满，底部压大号白字参数「5Gbps / Transfer Files in Seconds」「4K@30Hz / High-Definition Display」。
- 体积：「Fit in Your Palm」+ 两个青色圆角卡「0.47in Razor Thin Body」「1.76oz Lightweight Design」。

**标题写法**：参数就是标题——「100W Pass-Through Charging」「Dual 4K@60Hz Display」「10Gbps Ultra-Fast Data Transfer」。7 合 1 的「7-in-1」占上半张图。

**配色**
- 5 合 1（老款）：浅灰底，接口用青 / 紫 / 蓝三色图标区分；「4K」用金色徽章。
- 7 合 1（新款 Revodok Pro）：**整套深灰黑底**，白字标题，大数字「10Gbps」做成发光斜体。限制条件用**红色小字 Note** 直接写在标题下（「Note: Mac can't display different screen on two screens」）。

**数字可视化**：充电功率用「Input 100W → Output 95W / 85W」两个数字分别标在线缆两端；速度条「USB 3.2 ▬▬ 10Gbps / USB 3.0 ▬ 5Gbps」；双屏模式用 Windows / macOS 两列小屏幕示意图（A/B 不同画面，Mac 一格打红叉）。

**场景和人物**：桌面办公为主（外接显示器 + 笔记本 + 扩展坞放桌面），人物多为侧面专注工作，扩展坞在画面下方小比例出现；Before/After 桌面整理对比（A+ a15）。

**A+ 顺序**
- 5 合 1：开场「Ultra-Thin with Ultimate Power」→ 接口清单 → 100W PD（附 note）→ 5Gbps（附 note）→ 4K HDMI → 接口总览 → 兼容性（深底白卡）→ 系列横幅 → 品牌介绍。
- 7 合 1：系列横幅 → 品牌介绍 → 卖点总览卡（7 格黑卡：双屏 / 单屏 / 10Gbps / 100W / 铝合金 / 指示灯）→ **两块 Note + 两块 FAQ 纯文字**（DP 版本、Mac 只镜像、充电慢原因）→ 大场景 ×3 → 材质 / 指示灯 / 4 重保护三格 → 接口总览 → 10Gbps（绿勾红叉标出哪些口能 / 不能做什么）→ 透传充电 → Before/After → 双屏。

**和其他大类的差别**：信息密度最高，限制说明最多（note、FAQ 全写进图）；新款整套深色底；数字压在场景照上而不是放白卡里。

## 线材（B086ZGKYH8、B00LM2Y2U4）

**副图尺寸**：正方形 1500×1500。

**副图顺序**
- USB-B 线：主图 → 耐弯折（5,000+ bend tests）→ 打印场景 → MIDI 键盘场景 → 兼容性 → 接口说明（USB 2.0 ✓ / USB 3.0 ✗）→ 打印速度 → 长距离场景 → 结构剖面 → 另一种接头特写。
- RCA 线：主图 → Hi-Fi 客厅场景 → 双向传输 + 兼容 → 抗拉 / 尾部 → 剖面 + 噪声对比 → 耐用结构 → 四格场景 → 音箱场景 → 音质氛围图 → 多件装。
- 共同顺序：**耐用 / 主卖点 → 用途场景 ×2 → 兼容（接口对不对）→ 结构 → 更多场景**，场景图比例最高。

**版式**：顶部居中粗体标题，商品接头大特写斜放占对角线；剖面图用细引线 + 小字标层（「28AWG Tinned Copper Core」「Polyethylene Foam Shield」）。

**标题写法**：「Clear Printing」+「Never distortion or garbled」、「No Waiting For Printing」+「Up to 480Mbps transfer speed」、「Long Distance without Loss」、「Stable Transmission, No Electronic Noise」。标题讲**用的结果**，参数放副标题。

**配色**：浅灰 / 浅蓝底；接头金属银 + 镀金；绿色小标签「3.5mm」「2RCA」「UGREEN」。场景照偏暖色客厅。

**数字可视化**：超大白色数字压背景「5,000+」「15000+」，旁边小字「bend tests」；接口匹配用两格小卡「USB 2.0 B male ✓ / USB 3.0 B male ✗」。

**对比图**：RCA g05 底部「Others unstable / UGREEN stable sound」两段波形示意，图上没有标测试依据。

**场景和人物**：人物最多的大类——打印、音乐制作、客厅看电视、跳舞、DJ、户外露营；线材本身在画面里很小，靠场景说用途。

**A+ 顺序**：场景开场（「Excellent Stereo」或居家打印照）→ 品牌介绍 → 商品大图 + 品类名（「USB C to B Printer Cable」）→ 兼容卡 → 4 块左右纯场景（基本无字）→ 编织 / 接头 / 屏蔽结构各一块。

**和其他大类的差别**：用途场景最多、文字最少；A+ 后半段几乎是无字场景照；没有端口分配、温控这类技术图。

## 主图做法

- 充电器：纯白底，商品 3/4 斜角，无文字。65W Air 主图带一条随附的编织线（随货），可以参考。
- 线材：纯白底，接头大特写交叉摆放，无文字。
- 扩展坞：**B0BR3M8XHK 和 B0D1XSKZRJ 主图都摆了 U 盘、HDMI 线、USB-A 插头等不随货道具**，HDMI 插头上还印「4K」字样，用道具直接展示接口用途。

## 和 Anker 的区别

（Anker 规律见 `style-anker.md`）

1. **副图比例**：Anker 三类都用 4:5 竖图；UGREEN 只有充电器用 3:4 竖图，扩展坞和线材用正方形。
2. **强调色**：Anker 只用一个青蓝；UGREEN 浅色底上用品牌绿做小标签和百分比，扩展坞再加青 / 紫区分接口，新款扩展坞整套深色底，配色跨度更大。
3. **数字表现**：Anker 大数字多放在底部白卡；UGREEN 常把超大浅色数字当背景水印放在商品后面（「30W MAX」「5,000+」「15000+」）。
4. **限制说明**：Anker 把"不含 / 不适用"放进兼容卡的 Reminder 格；UGREEN 直接在图上写 note / 红字 Note，扩展坞 A+ 还放整块 FAQ 文字。
5. **对比图**：Anker 只比泛称并注明测试依据；UGREEN RCA 线有一张 Others vs UGREEN 波形示意，没有依据，不可学。

## 可以怎么借鉴（按需挑选）

- 可以把接口类商品的第一张副图做成"接口总览"：每个接口一根细引线 + 名称 + 括号参数。
- 可以考虑用超大浅色数字做背景水印，商品压在数字前面，数字和商品形成一个整体。
- 体积卖点可以用"百分比大字 + Smaller + 实际尺寸"，并放一个参照物（自家旧款或通用大充电器，不点名品牌）。
- 场景可以拼成 Home / Travel / Office 三格，每格一个短标签，一张图讲完适用场景。
- 端口分配可以用线框正面图按单口 / 双口 / 三口分块，引线标瓦数。
- 有使用限制的商品（扩展坞、转接头）可以把关键限制用一行小字 note 写在相关图下方，减少差评；可以考虑在 A+ 末尾放一块 FAQ。
- 结构剖面图可以用细引线 + 小字逐层标材料，引线端点用一个小强调色点。
- 线材类可以多放用途场景，让线在场景里小比例出现，A+ 后段可以考虑无字场景照。
- 颜色变体可以放最后一张副图，和主图同角度只换颜色。
- 对比图如果要做，只比泛称 Others，并且必须有实测或公开数据作依据，标在脚注里。
