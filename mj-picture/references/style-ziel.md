## 一、品牌通用规律

### 1. 浅、暖、留白多

- 底色是米白、暖灰、浅木色、灰绿、自然光室内，几乎不用深色底。和 REDTIGER / WOLFBOX 的深色科技风正好相反。
- 每个品牌一个低饱和品牌色，只用在标题和少量标注上：VASAGLE 酒红、SONGMICS 墨绿/青绿、FEANDREA 橙。
- 商品和场景占大部分画面，文字少，留白多。

### 2. 标题：左上对齐，主标题 + 一行说明

- 主标题左上对齐（不居中），品牌色，圆润无衬线体，2–4 个词：`Solid Structure`、`Fits Small Spaces`、`Ample Under-Bed Space`、`Keep the Mattress Securely in Place`、`Stable and Safe`。
- 下一行灰色小字讲具体事实：`Thick boards and steel frame for a solid structure`、`Fits suitcases, storage baskets or shoes for a tidy bedroom`、`Blends seamlessly with various room décor`。
- 需要时加短的项目符号（`• 2 Enclosed Cabinets • 2 Open Compartments`）。
- 语气温和、有节奏，常用对仗：`Line Up Your Shoes, Tidy Up Your Space`、`Live in Order, Live in Style`、`Set the Mood for Movie Nights`。

### 3. 副图顺序

1. 主图：白底商品。
2. 品牌开场：左上 Logo + 真实家居场景。
3. 尺寸图：暖色浅底，标线同时标 in 和 cm，承重用品牌色大数字放在上方（`44 lb`、`550 lb (250kg)`、`165 lb (75 kg)`），数字上方三个向下箭头。
4–8. 卖点细节：容量、结构、材质、可调脚垫、安装。
9. 场景或对比：`From Shoe Piles to a Tidy Space`、`With / Without`。
10. 其他颜色或款式：白底。

### 4. 细节图版式

- **上下两段 + 引线**：上半局部特写，下半材料特写（钢管横截面），细虚线连接，各配小标题。
- **一大几小**：上方大图，下方 2–3 张小卡，每张卡底部一条品牌色标签条（`Reinforced Base`、`Anti-Tip Kit`）。
- **场景 + 标注线**：细线引出小字说明各部位用途。
- **分屏多用途**：画面分 2–4 格，每格左上一个小标签（`Closet` / `Living Room` / `Bedroom`）。
- **安装爆炸图**：零件散开，旁边品牌色圆圈字母 A、B、C。
- **我们 vs 其他**：左右小图，标签 `Ours` / `Others`，比的是实物真实差异（抽屉拉出后是否变形）。

### 5. 主图

白底商品 3/4 角度。VASAGLE、SONGMICS 主图上摆绿植、书、杯子，FEANDREA 主图里有猫，用道具和宠物营造使用氛围。

## 二、按产品大小区分

### 小件（边几、鞋架，占地小）

- 卖点围绕“放得下、够用”：`Fits Small Spaces`（场景放在沙发边、窗边小角落），尺寸写在说明里（`This 11.8"D x 13.4"W x 22.8"H table fits tight spots`）。
- 承重数字依然放大，但画面更多讲收纳和摆放方式（正放 / 倒放、可叠加）。
- 场景取景近，常是一个角落，不拍整间房。

### 大件（床架、斗柜、大猫爬架）

- **尺寸靠参照物**：斗柜尺寸图旁站一个标了 `5'5" (165 cm)` 的人形剪影；床架 A+ `Pick the Perfect Bed Frame Height` 把 14" / 16" / 18" 三个高度并排，上方配三个坐姿小人示意坐上去的高度；猫爬架 A+ 里站一个标了模特身高的真人。
- **容量用实物计数**：斗柜 `Spacious Storage` 用一排衣物图标写能放多少（T 恤、裤子、袜子各多少件）。
- **空间当卖点**：床架 `Ample Under-Bed Space` 在床下塞满行李箱、收纳筐、鞋子，标 `12.4" (31.5 cm)` 离地高度，下方一排图标写能放什么（收纳筐、鞋、书、行李箱）。
- **规格表**：床架尺寸图下方加一张小表（高度 × Twin / Full / Queen / King），当前款用品牌色格子标出。
- **我们 vs 其他**：床架 `Non-Slip Mattress Retainer`、`Heavy-Duty Reinforced Legs` 都用左右小图 `Ours` / `Others` 对比结构细节。
- **选尺寸**：A+ 用一屏把同系列不同高度/尺寸并排（床架 14" / 16" / 18"；猫爬架 S–XXL 标高度和适用体重）。
- 场景取整个房间，商品在画面中占比小一些，强调融入家里。

## 三、按使用场景区分

- **客厅**：沙发、茶几一起出现，暖色自然光。
- **卧室**：床、床头灯、衣物；斗柜 A+ 一屏三格分别是 `Closet`、`Living Room`、`Bedroom`，说明一件家具能放多个房间；床架 A+ `Versatile Appeal` 用 `Minimalist` / `Modern` / `Industrial` 三种卧室风格分格展示。床架开场 `Solid Frame, Sound Sleep`。
- **玄关**：门、挂衣钩、鞋子摆满鞋架；对比图下方放一堆乱鞋作“之前”。
- **宠物（FEANDREA）**：
  - 真猫在每一层做事（睡、抓、看窗外），标注每个部位对应的猫的行为（`Bird Watching`、`Scratching`、`Hide and Seek`）。
  - 写出模特猫的信息（体重、年龄），A+ 甚至给每只猫做“档案卡”（名字、品种、性格、最爱的位置），手绘涂鸦线条，语气俏皮。
  - 选购图按猫的体重分 S / M / L / XL。

## 四、A+ 结构

- **VASAGLE**：每个房间一块场景横幅（左上一句短标题）→ 系列总览（顶部颜色切换标签，下方全系列线稿 + 名称，底部系列名横条）→ 品牌模块（理念、数据和奖项、公益）。
- **SONGMICS**：场景横幅 → 多房间分屏 → 系列总览（按颜色分屏）→ 品牌故事（74 项设计奖、媒体报道、植树数据）。
- **FEANDREA**：手绘风开场 → 猫档案卡 → 逐个卖点（易清洁、易安装、稳固、天然剑麻）→ 尺寸选购 → 品牌奖项和媒体。
- 共同点：A+ 偏氛围和系列，单个卖点在副图讲完；品牌信任信息放在 A+ 末尾的竖卡里。

## 和 REDTIGER / WOLFBOX 的区别

| | 致欧 | REDTIGER / WOLFBOX |
|---|---|---|
| 底色 | 浅、暖、自然光 | 深色、戏剧化光效 |
| 标题位置 | 左上对齐 | 顶部居中 |
| 强调方式 | 整个标题用一种低饱和品牌色 | 标题里一个强调词用高亮色 |
| 场景 | 真实家居、人和宠物 | 渲染感强的产品特写和夜景 |
| 数字 | 尺寸、承重、容量、适用范围 | 大数字、对比条、速度倍数 |
| A+ | 场景 + 系列总览 + 品牌故事 | 功能总览宫格 + 逐个功能 |

## 可以怎么借鉴（按需挑选）

- 想要干净、亲和的感觉时，可以用浅暖底色 + 一个低饱和品牌色，主标题左上对齐，下面一行灰色事实说明。
- 尺寸图可以考虑把承重、容量这类关键数字放大到上方，标线同时标 in 和 cm。
- 大件商品可以用参照物交代尺寸：人形剪影标身高、真人模特标身高（比如球友身高和推车把手高度）。
- 结构、材质类卖点可以用“上下两段 + 引线”或“一大几小 + 标签条”版式。
- 空间、收纳这类“用起来多出来的好处”可以单独做成一张卖点图（比如床下能放什么），前提是实物真有。
- 安装图可以用爆炸图 + 字母编号，和说明书编号一致。
- 有多个型号时，A+ 可以考虑做“同系列选购”一屏，写清每款适合谁（比如 GC1 / GC2）。
- `Ours / Others` 对比只比泛称 Others，且比的必须是实物真实差异、有依据。
