## 品牌通用规律（各品类都有）

- **副图标题在顶部居中**，1–2 行，常配一行副标题。字体是圆润的几何无衬线体，标题用中粗，不用斜体、描边或渐变。标题整句一个颜色（深灰或黑，压在照片上时用白），不做双色标题。
- **标题是“功能 + 好处”的短句**，3–7 个单词，例如 “Built-In Storage, No Monthly Fee.”、“Quick Start for Busy Working Moms”。
- **数字条**：标题下面放 3–4 个“大数字或图标 + 小字说明”，中间用细竖线隔开，例如 E21 的 4K | 8× | Auto-Focus | 360°，E20 的 DIY | 4 | 7 | 3。这是 eufy 最常见、跨品类都有的元素。
- **只有一个强调色**：eufy 蓝（约 #0A6AA8 一类的中蓝），用在关键数字、图标、App 界面里的按钮。吸奶器换成暖橙（HeatFlow、30%），其他品类没见到第二种强调色。
- **A+ 横幅版式统一**：1464×600，左边 1/3 留白放文字（小字型号名 + 两行标题 + 3–4 行正文 + 一排小线框图标），右边 2/3 放照片。照片常用一条弧线切开，和左边的浅色底衔接（吸奶器、门锁、门铃都这样）。
- **A+ 以 Q&A 文字块收尾**：扫地机器人、门锁都在 A+ 最后放 2–4 块“Q / A”问答（例如 “How do I choose the right water level…”），然后是尺寸图、包装清单。
- **品牌故事**按事业部分开：扫地机器人用 “ANKER eufy” 开头 + 奖项墙 + “Trusted by 1,000+ Pet Families” + 新品卡；安防类（门铃、摄像头、门锁）共用 “Home Outdoor PTZ Camera No.1 / 16,000,000+ / Local Security, No Monthly Fee” 三块；母婴类共用 “Expert Innovation for Effortless Care / Recommended by 100+ IBCLCs / 500,000+ Families”。
- **主图做法**：除 11S MAX 是纯商品白底外，其余样本主图都把手机 App 界面（有的还有手表）和商品放在一起；S1、E20 主图还摆了全部配件。手机、手表作为道具，展示 App 联动。

## 1. 扫地机器人（11S MAX、C28，参考 E25）

**副图顺序**（C28）：新旧型号对比 → 拖布自清洁结构 → 跟 Others 对比 → 防缠毛 → 吸力 → 全能基站 → 避障导航 → App。卖点按“拖地 → 吸尘 → 基站 → 智能”的顺序走。11S MAX 是老款：媒体背书（CNET / Forbes / WIRED）→ 吸力 → 地毯增压 → 清扫模式 → 静音 → 使用说明。

**版式**：
- 副图是竖图 1200×1500（4:5）。新款（C28、E25）是“顶部大标题 + 中间大画面 + 底部 3 张小卡”：吸力图底部三张实拍卡 Hair / Pet Food / Debris and Dust；基站图底部 5–6 张深色小卡 Self-Emptying / Hot Air Drying 等。
- 结构图用**深色底 + 半透明爆炸图 + 数字编号 1–4 的步骤**（E25 g03、C28 g03 “HydroJet Self-Cleaning Roller Mop”），这是全品牌唯一大量用深色底的地方。
- 老款 11S MAX 是另一套：标题放在左上角浅色条里，前面一条青色竖线，画面是大幅实拍，文字很少。

**标题写法**（引图上原文）：
- 结果型：“Stop Spreading Dirt While You Clean”
- 参数型：“15,000 Pa High-Power Suction”
- 结构名：“DuoSpiral™ Detangle Brushes”
- 老款更短：“Quietly Powerful”“Powerful Suction”

**数字可视化**：吸力值做成**画面里的巨型斜体透视字**，像印在地上（C28 g06 “15,000 Pa”、E25 g04 “20,000Pa”），从机器底部打出蓝白气流。其他参数用 “270 RPM / 10N / 272.5 mm” 这样竖排的三张小卡（A+ a15）。“0% Hair Tangling*” 配星号脚注说明测试条件。

**配色**：浅灰蓝底为主（#E8EDF2 一类），结构图和隐私图用深海军蓝 / 黑底，强调色 eufy 蓝。木地板、地毯是主要场景色。

**场景和人物**：宠物（金毛、柯基、猫）出镜频率最高，人物多在背景沙发上，机器在前景。人物不看镜头。

**对比图**：C28 g02 是跟**自家上一代** X10 Pro Omni 对比（推荐款加蓝框 + “Recommended” 标签，左右用 VS 圆标）；g04 是 “C28 Omni / Others”，左边浅色卡、右边深色卡，各配一句结果；A+ 用 “Typical Robot Vacuum ✕ / Omni C28 ✓”；E25 的拖布代际对比写 Gen1 Flat Mop / Gen2 Dual-Plate Mops / Gen3 HydroJet，比的是技术类型，不点名竞品。

**A+ 顺序**（C28）：品牌故事 → 吸力 → 拖布结构（4 宫格说明）→ 拖布参数 → 抬拖 10.8 mm → 代际对比 → 防缠毛 VS → 基站 → 75 天集尘 → 热风烘干 → 自动上下水 → 隐私（深蓝盾牌）→ App 拼图 → 语音 → 分房间清扫 → 多楼层地图 → 4 个小功能卡 → 尺寸 → 包装清单 → Q&A × 3。

**和其他品类的差别**：信息最密，几乎每张图都有底部小卡或编号步骤；唯一大量用深色底和爆炸图；唯一在副图里直接放 “Others” 对比。

## 2. 吸奶器（S1、E20）

**副图顺序**（S1）：加热技术（HeatFlow）→ 专家共创节奏 → App 调节 → 吸力 / 出奶量 → 静音隐私 → 舒适贴合。E20 是：快速上手 → App → 4 个零件好清洗 → 静音隐私 → 材质安全 → 三款型号对比表。

**版式**：
- 正方形 1500×1500。顶部白色或浅色标题，**下面整张是实拍照片**，标题直接压在照片上方的留白处，没有卡片。
- 数字条放在标题下（S1 g07 “4 Flange Sizes | Soft Silicone | 105° Ergonomic Design”）。
- 技术图用**半透明产品 + 暖橙光晕**表现加热（S1 g02），清洁图用产品零件漂在水中、带气泡（E20 g04）。

**标题写法**：
- 好处型：“Comfort for all moms”
- 数字型：“Pioneering HeatFlow for 30% More Output*”
- 场景型：“Quick Start for Busy Working Moms”
- 隐私型：“Discreet, Quiet and Slim for Privacy”

**数字可视化**：橙色大字 + 向上箭头（“30%↑”、“10 ml↑”）；静音用声波图标 + “<46 dB”。带星号的数字都有脚注说明来源（“Based on actual usage feedback from over 300 eufy pump users”）。

**配色**：奶油、米白、裸粉、浅驼，整套暖色；强调色换成**暖橙 / 珊瑚粉**（HeatFlow 字样、30%），只在背书块用 eufy 蓝。没有深色底。

**场景和人物**：女性用户占画面主体，办公室、客厅、开车、户外露台，强调“戴着吸奶器照常生活”。哺乳顾问（IBCLC）本人出镜，配手写签名（S1 g03、A+ a06），这是背书方式。人物多数微笑但不看镜头。

**A+ 顺序**（S1）：加热技术 → 不同身材女性 + 3 个罩杯尺寸 → 吸力 → 静音 → 便携（开车场景）→ 专家共创节奏 → App 控制 → 记录进度 → 计划 → 易清洗 → 组装图 → 清洗步骤 → 媒体背书 → 专家墙 + 奖项。E20 多一块“Find Your Perfect Flange Fit”三步测量尺码。

**和其他品类的差别**：唯一整套暖色、强调色不是蓝色的品类；人物比例最高；用专家本人和“100+ IBCLCs”头像墙做背书；A+ 后段有完整的使用教程（组装、清洗、尺码测量）。

## 3. 可视门铃（E340、C31）

**副图顺序**（E340）：双摄 + 包裹识别 → 2K 夜视 → 本地存储省钱 → 实时通知 + 对讲 → 有线或电池两种供电 → 配件。C31 把“No Monthly Fee”放到第 1 张副图。

**版式**：
- 浅灰白底，标题居中、黑色、两行，下面一行灰色副标题。
- 识别功能用**蓝色取景框角标**框住人脸和包裹（E340 g02），旁边配线框图标 + 小字（Face Recognition / Package Detection）。
- 画质对比用左右两张同场景照片，底部标 “1080P”（灰）和 “2K”（蓝）（C31 g04）。
- 日夜对比用一张图左白天右夜晚，上面一条刻度尺带太阳和月亮图标（C31 g06 “24/7 Non-Stop Surveillance”）。

**标题写法**：
- 省钱型：“No Monthly Fee, No Price Hikes.”
- 功能型：“Dual Cameras with Delivery Guard”
- 选择型：“Wireless or Hardwire Installation, Your Choice”
- 极短：“Live Video Call”

**数字可视化**：省钱图是全品牌最醒目的数字：“Save **$300** over 3 years*”，$300 用超大号 eufy 蓝粗体，下面放一栋剖开的 3D 小房子，门铃发蓝光；脚注写明对比的是其他云存储方案的订阅费。分辨率用黑底白字的 “2K FHD” 徽章。

**配色**：浅灰白底 + eufy 蓝；夜视图用真实夜景（深蓝），不用纯黑底。

**场景和人物**：快递员、家人、孩子站在门口，人物看镜头（门铃视角），是全品牌唯一大量正脸看镜头的品类。手机 App 画面常和门铃并排出现。

**A+ 顺序**（E340）：安防品牌故事 3 块 → 开场横幅（T3 白金奖 + 三个参数徽章 + 媒体评语引文）→ 双摄 → 包裹守护 → 2K → 彩色夜视 → 双灯 → 省 $300 → 本地 8 GB → HomeBase 扩容 → 背面结构图。

**和其他品类的差别**：卖点围绕“不收月费”反复出现（副图、A+、品牌故事各一次）；用取景框和 App 截图模拟“门铃看到的画面”；人物正脸看镜头。

## 4. 婴儿监视器 / 室内看护摄像头（E30、E21）

**副图顺序**（E30）：4K 清晰度 → 360° 视角 → AI 追踪人宠 → 夜视两种模式 → 隐私模式 → 智能家居生态 → 不收月费。E21：4K 夜视看呼吸 → 降噪睡眠 → 屏幕 + App 双端 → 一键断 Wi-Fi → 插电或电池。

**版式**：
- 正方形 1500×1500。E30 是浅灰底 + 顶部黑色标题 + 灰色副标题 + 一张或上下两张圆角照片卡；E21 是整张实拍、标题压在照片顶部，底部做一个**大弧形遮罩**和下一张图衔接。
- 清晰度对比用同一画面放两张小卡，标 “2K HD” 和 “4K UHD”（E30 g02）；夜视用上下两张卡标 “Color Night Vision / Infrared Night Vision”（E30 g05）。
- 追踪功能用蓝色角框框住宠物（E30 g04）。

**标题写法**：
- 场景型：“Say Goodnight and Watch Every Breath with NightOptics™”
- 隐私型：“Full Privacy and Security in One Switch”
- 轻松型：“Nighttime, Bright Time”
- 功能型：“Advanced AI: Accurate Detection & Tracking”

**数字可视化**：E21 g02 把 “4K” 做成**画面里的发光大字**（立在婴儿床前），和扫地机器人的“地面巨字”同一手法；数字条 “4K | 8× | Auto-Focus | 360° Pan”。“Wi-Fi Off” 用大号白字 + 一个放大的开关按钮特写。

**配色**：E30 浅灰白 + eufy 蓝；E21 暖米色、浅木色，夜间图用暖黄台灯光，整体比 E30 柔和。

**场景和人物**：婴儿睡觉、妈妈抱孩子、宠物在客厅跑；夜间场景多（卧室、婴儿床）。A+ 里有祖父母、外出购物的人在看 App（E21 a02 “Check in Anywhere”）。

**A+ 顺序**（E21）：远程看护 → App 远程 → 一键断网 → 双画面 → 传输距离 / 加密三拼 → 夜视 → 变焦 → 自动对焦 → 云台视角 → 安装方式 → 母婴品牌故事。E30 是安防那套：开场横幅（型号小字 + 两行标题 + 一排参数徽章 + “Works with Apple Home”）→ 4K → 视角切换 → 360° → AI 识别 → 追踪 → 夜视 → 对讲 → 本地存储 → HomeBase → 生态 → 省 $300。

**和其他品类的差别**：同一品类两种调性：E30 走安防的冷灰 + 卡片，E21 走母婴的暖色 + 整图 + 弧形遮罩；夜间场景占比最高；“断网 / 隐私开关”单独占一张图。

## 5. 智能门锁（C220、C30）

**副图顺序**（C220）：指纹识别速度 → 电池续航 → Wi-Fi 直连 → 远程控制 → 安装前尺寸核对 → 15 分钟安装。C30：包装更新说明 → Wi-Fi → 4 种开锁方式 → 联动门铃 → 15 分钟安装 → 安装前核对。

**版式**：
- 竖图 4:5 和正方形混用。标题顶部居中、黑色粗体，商品装在真实门上拍。
- 4 种开锁方式用 **2×2 四宫格**，每格左上角一个蓝色图标 + 标签（App Control / Passcode / Voice Control / Physical Key）。
- 尺寸核对图（“Check Compatibility Before Purchase”）把门的剖面拍出来，用蓝色圆角标签标尺寸（Cross Bore Diameter 1½" or 2⅛"），底部放“能装 ✓ / 不能装 ✕”两张小图。这是唯一专门帮买家避免退货的图。

**标题写法**：
- 结果型：“Reliable Power that Lasts Twice as Long”
- 极短：“Control from Anywhere”
- 动作型：“Unlock the Way You Want”
- 提醒型：“Check Before Purchase”

**数字可视化**：C220 g03 是全品牌少见的**黑底**图：发蓝光的巨型 “8 Months*”，下面两条进度条对比 “eufy C220 Smart Lock”（长、蓝）和 “Other Smart Lock with Built-in Wi-Fi”（短、灰），比的是泛称且带脚注。指纹速度用 “0.3s” + “AI Chip” 两个蓝色大字放在底部白色圆角条里。耐用测试做成四行竖排数字（100,000 Usage Test / 72 Hour Salt Spray Test / 2000N / 144 Hour）。

**配色**：暖白、米色、木门色为底；强调色 eufy 蓝；只有电池图用黑底。

**场景和人物**：孩子背书包进门、一家人回家、手指按指纹；App 通知用**浮层气泡**叠在照片上（“Front door was locked by Jim.”、“Hey Alexa, unlock the door.”）。

**A+ 顺序**（C30）：安防品牌故事 3 块 → 开场（一家人进门 + “No Bridge Required”）→ 开锁方式四宫格 → 夜间背光 → 防偷窥密码 → 适配多种门 → 自动上锁 → 远程查看 → Alexa → 访客权限 → 租客临时密码 → 开关门通知 → 低电提醒 → DIY 安装 → BHMA 认证金盾 → 安全加密 → 防水 → 售后。C220 的 A+ 图上几乎没字，标题和正文是 A+ 模块的网页文字（“Your Finger is the Key”等），最后有“Find Your eufy Smart Lock”型号对比表和 Q&A。

**和其他品类的差别**：功能点最多（20 块 A+），每块只讲一个功能、文字很短；安装和尺寸核对单独占 2 张；App 通知气泡是主要的叙事手段。

## 可以怎么借鉴（按需挑选）

- 可以在副图标题下放一行 3–4 格的“数字 / 图标 + 小字”条，用细竖线分隔，比堆卡片更省空间。
- 可以考虑只用一个强调色贯穿全套图；如果是母婴、个护这类需要温暖感的商品，可以考虑换成暖色调，不必用蓝。
- 核心参数（吸力、分辨率、续航）可以考虑做成画面里的大字（像印在地上或立在场景里），一套图里用 1–2 次就够。
- 内部结构复杂的卖点，可以考虑用深色底 + 半透明爆炸图 + 1–4 编号步骤讲清楚原理。
- A+ 横幅可以采用“左侧留白放文字、右侧放照片”的统一版式，每块只讲一个功能；照片和底色之间可以用弧线衔接。
- 安装类商品可以考虑单独做一张“购买前核对尺寸”的图，标清能装 / 不能装的情况，减少退货。
- 有 App 的商品，可以把通知做成浮层气泡叠在生活照上，比单独放手机截图更好懂。
- A+ 末尾可以考虑放 2–4 块 Q&A 文字块和包装清单，回答买家常问的问题。
- 背书可以考虑用真实专家、认证机构或测试数据，配脚注写清来源。
- 对比图可以做，但只能比泛称 “Others” 或 “Typical …”，或者比自家上一代，并且必须有依据（测试条件写进脚注）；不点名竞品。
- 不要照搬：eufy 的 “Save $300 over 3 years” 立在它自己的“不收月费”模式上，我方没有同样的依据时不要用类似的省钱算式。
