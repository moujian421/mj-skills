# 手机端 A+（600×450）参考

2026-10-23 用内置浏览器手机模式（375×812，Android UA）抓了 9 个参考品牌、21 个热卖链接的手机端 A+，共 223 张，按手机实际显示宽度 375px 逐张看。**仅供参考**，规则以 SKILL.md 为准。

## 先说结论

- **21 个链接全部做了单独的手机版**（地址里是 `__CR0,0,600,450` 或 `1200,900` 的高清版），没有一个是把电脑端 1464×600 直接缩小。手机上看到的 A+ 就是这套 600×450 图。
- 手机版不是把电脑端裁一块，而是**重新排版**：电脑端的“左文字、右图片”，到手机端几乎都改成“上文字、下图片”。
- 所以 A+ 需求要按手机端单独写版式；电脑端只是在手机版的基础上横向展开。

## 手机端常见版式

### 1. 上文字带 + 下图片（最常用）

```
┌──────────────────────────┐
│     主标题（居中，1–2 行）    │  上方 15–25%，纯色或浅渐变底
│   副标题 / 参数条（1 行）     │
├──────────────────────────┤
│                          │
│   照片或产品图（下方 75–85%）  │  常做成带边距的圆角卡片
│                          │
└──────────────────────────┘
```

- Anker 充电宝：`100W Max Output for / Continuous Entertainment` 两行居中，下面一排白色参数小卡（`USB-C1 100W Max` …），再下面一张场景照。
- eufy 吸奶器：奶油色上带写 `Carry Bag for Pumping Anywhere`，下面一张圆角照片卡，12 块全用同一模板。
- Dreame 扫拖机器人：`20,000Pa Vormax Suction` + 两行灰色说明，下面产品图和橙色大数字。
- EcoFlow 冰箱：只有一行场景名 `Car Camping`、`Tailgating`，下面整幅户外照片，最好读。

### 2. 文字叠在图上（深色或场景图）

- EcoFlow 电站、WOLFBOX、REDTIGER：深色图，标题直接压在画面上方的暗部，白字 + 一个强调色。
- VASAGLE 床架：标题放左上角的留白墙面上（`Ample Under-Bed Space`），品牌酒红色。
- 要求原图上方或一侧本来就有干净区域，不然字会被背景吃掉。

### 3. 纯图片，不放字

- Govee 灯带：多块纯场景，只换房间和灯色。
- eufy 门锁：12 块里大部分图上没有字，标题和说明写在 A+ 模块自带的文字栏里（网页文字，不是图片文字）。手机上网页文字清晰、可缩放，也能被搜索读取。

### 4. 电脑端一块拆成手机端几块

- UGREEN 充电头：电脑端一块讲完单口 / 双口 / 三口供电，手机端拆成 `Single Port Charging`、`Two Port Charging`、`Three Port Charging` 三块，每块一张线框图，数字够大。
- 卖点总览宫格（Anker、Dreame、EcoFlow、冰箱）：电脑端横排 6–8 格，手机端改成 2×3 或 3×3 小宫格，每格只留 2–4 个词的标签。

## 字号和字数（375px 显示宽度下的观察）

- 主标题在手机上约 17–20px，对应 600 宽画布约 28–32px；**多数品牌允许两行**，每行约 20–26 个字符，居中。
- 副标题 / 说明在手机上约 10–12px，对应画布约 16–20px；三行以上的说明在手机上已经很难读（REDTIGER `Time-lapse Parking Monitor` 的三行说明、FEANDREA 猫档案卡的小字）。
- 大数字（`20,000Pa`、`100%`、`45 min`、`<46 dB`）在手机上是最显眼的元素，字号常比主标题还大。
- 各品牌手机端 A+ 的实测字号、字数、排版见 typography-stats.md 和各品牌文件末尾；参照哪个品牌的风格，就按哪个品牌的数值。

## 写 A+ 需求时可以怎么用

- 每块 A+ 先写手机端 600×450 版式，再写电脑端 1464×600 怎么展开（不想单独写时，注明“电脑端左右展开同内容”）。
- 手机端优先用“上文字带 + 下图片”；只有图片上方或一侧本来就干净时才叠字。
- 电脑端一块信息很多（多张小图、多组数字）时，手机端可以考虑拆成 2–3 块，每块一个点。
- 总览宫格到手机端改成 2×3 / 3×3，每格标签 2–4 个词。
- 说明文字超过两行，在手机上就难读；能用图标、数字、参数小卡代替的就代替。
- 纯氛围场景可以不放字，标题写进 A+ 模块的文字栏（网页文字），手机上更清晰。
- 交付前把 600×450 稿缩到 375px 宽看一遍，主标题、数字、标签都要一眼能读。
