## 品牌通用规律

- **两套底色体系，按大类切换**：电站用暗调（深灰到黑，加暖棕/琥珀渐变）；太阳能板和冰箱用亮调（天蓝/浅灰天空、白卡片）。
- **强调色只有一个，只用在数字上**：电站用琥珀橙（`45 Min`、`3.43 Hours`），太阳能板用亮蓝（`25%`、`15.4 lb`）。标题本身全白或全黑，不上色。
- **标题顶部居中，几乎都是一行主标题加一行副标题**。主标题常用全大写无衬线粗体（太阳能板、DELTA 3 Classic）或首字母大写（DELTA 3 Max、冰箱）。同一款商品内统一，不混用。
- **数字作为视觉主角**：大号数字，单位缩小一档，下面配极小的条件说明（`0-80% in`、`(1300W)`）。不用饼图、雷达图。
- **场景是真实照片质感的生活片**：人物自然在做事（做饭、睡觉、办公、野餐），不对镜头摆拍。商品在画面里占比不大，但光线把它打亮。
- **品牌故事 4 块各款通用**：展厅全家福 + "About EcoFlow" 三个数字 + USA TODAY 奖项 + 媒体奖项墙。
- **A+ 几乎全是 1464×600 横幅**，一块讲一件事，很少用 4 宫格小图（太阳能板 a02、电站 a05 的拼贴总览除外）。
- **主图**：电站和太阳能板都是纯白底、无文字、3/4 角度单机，干净。冰箱主图加了一辆带 EF 标的折叠推车，作道具，展示户外搬运场景。

## 大类一：便携电站（DELTA 3 Classic / DELTA 3 Max）

### 副图顺序
| 位置 | DELTA 3 Classic（方图 1500×1500） | DELTA 3 Max（竖图 1200×1500） |
|---|---|---|
| g02 | 4 种充电方式 | <10ms UPS 自动切换 |
| g03 | 输出功率 + 设备续航 | 输出功率 + 设备续航 |
| g04 | 6 个输出口 | 电芯/安全（爆炸图） |
| g05 | 10ms UPS | 4 种充电方式 |
| g06 | 30dB 静音 | App 省电模式 |
| g07 | App 控制 | 25dB 静音 |
| g08 | 便携（尺寸+重量） | 轻 13%（和自家旧款比） |
| g09–10 | 白底套装图（加太阳能板） | 白底套装/配件图 |

规律：**前 4 张讲"充得快、带得动、不断电"**，静音、App、便携放后面，最后用白底套装图收尾。两款顺序不同，新款把"不断电"（UPS）提到第一张，说明他们会按卖点优先级重排，不固定模板。

### 版式结构
- 顶部：主标题（白，1 行）+ 副标题（灰白小字 1 行）。
- 中部：暗调生活场景，商品放在画面中下部，靠灯光或屏幕亮光突出。
- 底部：深色半透明数据条，4 等分，每格 = 线性图标 + 设备名 + 琥珀色大数字（g03、g05）。

### 标题写法（实际文案）
- `4 Ways to Charge Up` / 副标题 `Ready in Just 68 Min`
- `Zero Downtime Built-in UPS` / `<10 ms Auto-switch`
- `30 dB WHISPER QUIET`
- `Cut Costs, Not Comfort`
- `Lightweight Design, 13% Lighter`
- `POWER FOR EVERY SCENARIO`

写法：主标题是"结果 + 数字"或短口号，副标题补一个具体数字或条件。

### 配色和底色
- 底：深灰/黑，夜景和室内暖灯；A+ 左侧文字区用黑到暖棕的渐变。
- 强调色：琥珀橙，只给数字和进度条（`0-80%` 进度条是琥珀渐变）。
- 商品本身是银灰色，在暗底上很显眼。

### 数字/参数可视化
- **充电时间**：两根横向进度条 `0-80% → 45 min`、`0-100% → 60 min`（A+ a06、a08、a09）。
- **续航**：设备图标网格（2×2 或 1×4），每格写 `设备名 / 58 Hr / (10W)`，功率放括号里当依据。
- **静音**：一条分贝曲线，标出 `25dB` 自家值和 `30dB 图书馆`、`60dB 说话` 参照（g06/g07、A+ a15/a11）。用生活参照代替和竞品比。
- **太阳能充电**：多条长短不同的横条比较 500W/400W/200W 输入的充电时间（Max A+ a04）。
- **轻量化**：两根条形对比 `DELTA 3 Max 44.7 lb` vs `Previous Model`，比的是自家旧款。

### 户外场景和人物
- 室内居多（厨房、卧室、书房、客厅），户外是露营桌、RV 旁、院子里。
- 人物不看镜头：做饭、睡觉、对着电脑工作、递东西给孩子。
- 夜景多：用"窗外暗、屋内亮"表达停电时照常用电。

### A+ 模块顺序（DELTA 3 Max 为例）
1. 卖点拼贴总览（8 宫格，每格一句短标题）
2. 交流快充 → 发电机充电 → 太阳能充电 → 车充（每种充电方式各一块）
3. 4 块续航分场景：厨房 / 客厅娱乐 / 书房办公 / 露营 / 工具（左侧黑棕底数字网格 + 右侧场景照片）
4. 静音 → 大功率 → App → 便携
5. 电芯 → 电芯一致性 → 耐用（4 宫格）
6. 品牌故事 4 块

**和其他大类的差别**：唯一用暗调的大类；参数最多，几乎每块都有数字；分场景续航是电站特有的做法。

## 大类二：便携太阳能板（160W / 220W）

### 副图顺序
1. 转换效率（`25%`，TOPCon / N-type 电芯）
2. 支架角度 + 角度指示器（设置简单）
3. 耐用（ETFE 膜、分层图）
4. IP68 防水防尘（左雪右沙漠的分屏）
5. 轻便（收纳包 + 折叠/展开尺寸 + 重量）
6. 适配自家电站 + 充电时间
7. What's in the box
8. （220W）白底第二视角

规律：**效率 → 好用 → 耐用 → 便携 → 兼容 → 包装清单**，从"发电多少"讲到"带出门"。

### 版式结构
- 顶部：全大写粗体黑字主标题（2 行居中），1 行灰色副标题。
- 中部：板子平铺或斜立在草地、沙滩、雪地上，天空淡蓝。
- 数据用白色半透明圆角卡浮在画面上（g07 尺寸卡、g08 电站兼容卡）。

### 标题写法（实际文案）
- `UNMATCHED 25% EFFICIENCY`
- `QUICK & EASY SETUP`
- `BUILT TO WEATHER THE STORM` / `IP68 Waterproof & Dustproof`
- `LIGHTWEIGHT AND PORTABLE`
- `OPTIMIZED FOR EcoFlow POWER STATIONS`
- `WHAT'S IN THE BOX`

### 配色和底色
- 天蓝到白的渐变天空 + 自然地面（草/沙/雪）。
- 强调色亮蓝，只给数字（`25%`、`30°-60°`、`15.4 lb`）。
- 包装清单和细节图用浅灰白卡片底。

### 数字/参数可视化
- **效率**：太阳 → 一块蓝色高亮电芯写 `25%` → 电池图标，画弧形箭头表示能量流（g02）。再加两根进度条：TOPCon 25% vs 单晶 21–23%，比的是技术类别，不点名品牌。
- **双面增益**：折线图，5 种地面（草地 7.21% → 镜面 24.85%）背面增益（220W g03）。
- **角度**：角度量角示意 + 指示器特写放大圆（g04）。
- **耐用**：板子分层爆炸图，左边 3–4 个线性图标列表。
- **兼容**：一排自家电站小图，下面蓝字写充电小时数。

### 户外场景和人物
- 场景是露营、房车、皮卡后备、海滩，人物多为蹲下摆板、提包走路，常只拍半身或腿脚。
- 人物不是重点，重点是"板子在户外、太阳很大"。

### A+ 模块顺序（220W）
1. 产品 + 一句定位横幅（雪地 + 电站）
2. 卖点 7 宫格总览
3. N 型电芯 → 双面发电 → 角度调节 → 耐用 3 联图
4. 便携（收纳包 + 尺寸重量）→ 适配电站充电时间
5. 品牌故事 4 块

**和其他大类的差别**：亮调、全大写黑字标题、图表化程度最高（折线、进度条、爆炸图）；人物最少；有包装清单图，电站没有。

## 大类三：户外电池冰箱（GLACIER Classic 55L）

### 副图顺序
1. `Up to 43 Hours of Fresh`（续航 + 和普通保温箱对比）
2. 5 种充电方式（5 宫格照片）
3. App 远程控制
4. 快速制冷（降温曲线）
5. 双侧开门
6. 多场景（超市购物、露营、徒步 3 宫格）
7–9. 白底主图变体 / 无推车单机

规律：**第一张副图就放场景大片 + 对比**，先讲"冰能保持多久"这个结果，参数放后面。

### 版式结构
- 上 2/3 场景照片 + 顶部白字标题；下 1/3 黑底分成两格做对比（g02）或做宫格（g03、g07）。
- A+ 大量用"上方居中黑字标题 + 下方整幅场景照片"，几乎不叠字。

### 标题写法（实际文案）
- `Up to 43 Hours of Fresh` / `No melted ice, No soggy food`
- `It's All on the App`
- `Enjoy Fast Cooling/Freezing` / `Cools down from 25°C to 0°C in 25 minutes`
- `Dual-Sided Door Access`
- `Perfectly Designed for Every Journey`
- A+ 场景块标题只有 2 个词：`Car Camping`、`RV Camping`、`Tailgating`、`Tent Camping`

### 配色和底色
- 户外自然光：草地、海滩、红岩沙地，色彩饱和、暖。
- 文字区黑底或白底，无品牌强调色；数字不单独上色。
- 冰箱里装满彩色食物（蔬果、饮料）做色彩点。

### 数字/参数可视化
- **续航**：标题直接写 `43 Hours`，副标题写 `298Wh` 电池。
- **降温**：一条温度下降曲线，标 `25 minutes`。
- **对比**：左 `Insulated Cooler`（泛称普通保温箱，冰块化水、食物泡湿）vs 右 `GLACIER Classic`（干爽、整齐），用照片对比，不写数字。
- **规格**：A+ 末尾 3 个尺寸对比表（罐数、升数、内外尺寸、重量）。
- **兼容**：A+ 一张兼容表格（打勾 + 接口名）。

### 户外场景和人物
- 人物多、动作多：举杯、递饮料、跪在沙地取东西、推购物车、徒步。
- 场景跨度大：海滩、露营帐篷、车尾 tailgate、超市停车场、RV 车厢。
- 一个场景一块 A+，每块只用 2 个词标题。

### A+ 模块顺序
1. 品牌主视觉横幅（海滩亲子 + 一句定位 `Pack the Chill, Chase the Thrill`）
2. 卖点宫格（双温区、90 罐、43 小时、3 个尺寸、App）
3. 5 块场景：车露营 / RV / 购物 / tailgating / 帐篷露营
4. 续航 → App → 对比保温箱 → 当充电宝 → 智能模式
5. 兼容表 → 3 尺寸规格表 → 品牌故事 4 块

**和其他大类的差别**：人物和生活感最强，参数最少；场景按"用在哪"分块而不是按"功能"分块；有系列尺寸对比表。

## 对户外用品的借鉴

用户卖高尔夫推车这类户外运动用品，下面是 EcoFlow 户外场景图里可以借鉴的手法：

1. **一个场景一块 A+，标题只写场景名**（冰箱的 `Car Camping`、`Tailgating`）。推车可以考虑拆成"球场 18 洞""停车场到发球台""车尾箱收纳"几块，每块 2–3 个词。
2. **人物在做事，不看镜头**。可以拍球手边走边看球道、从推车上拿水，推车在画面里占三分之一左右，用光线把它打亮。
3. **收纳/折叠用"尺寸卡 + 重量大数字"浮在场景上**（太阳能板 g07：折叠尺寸、展开尺寸、`15.4 lb`）。推车可以考虑一张图同时放折叠和展开两个状态，配一个强调色重量数字。
4. **耐用卖点用分层爆炸图 + 左侧 3–4 个线性图标**（太阳能板 g04）。推车车架、轮子、面料可以考虑这样拆层展示。
5. **防水/耐候用分屏场景**（太阳能板左雪地右沙漠）。推车可以考虑"晨露草地 / 雨后球场"分屏，前提是有实际防水等级或测试依据。

## 可以怎么借鉴（按需挑选）

- 整套副图可以只用一个强调色，并且只给数字用；标题保持纯白或纯黑。
- 想做高级感，可以考虑一套底色贯穿全部副图（电站全暗、太阳能板全亮），不在同一套图里混用。
- 数字可以写成"大数字 + 小单位 + 括号里的条件"，例如 `58 Hr (10W)`，条件给依据，也避免夸大。
- 对比图可以比泛称 `Others`、普通款或自家旧款（EcoFlow 比的是 `Insulated Cooler`、`Previous Model`、单晶电芯技术），必须有实测或公开依据，不点名竞品。
- 用生活参照代替抽象参数，例如分贝曲线标"图书馆""说话"，推车可以用"一局 18 洞""一个车尾箱"做参照。
- A+ 开头可以放一张卖点拼贴总览，后面每块只讲一件事。
- 竖图（1200×1500）可以考虑用在场景多的副图上，手机端占屏更大；DELTA 3 Max 全套是竖图，Classic 是方图，两种都在用。
- 包装清单可以用浅灰白卡片分格，每格一行"数量 × 名称"。
