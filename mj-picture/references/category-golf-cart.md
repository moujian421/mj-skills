# 品类：高尔夫推车（AH-GC1 / GC2）

只在做高尔夫推车或结构类似的折叠推车时读。做法来自 AH-GC1、GC2 两款，换品类时不要照搬。

## 图位顺序（AH-GC1，已确认）

主图 → 360° 前轮 → 手刹（一级差异）→ 折叠进后备箱（刚需，7/7 竞品有）→ 4 档手柄 → 球包固定 → 配件（7/7 竞品有，基础）→ 尺寸规格 → 球场实景。

GC2 的一级差异是一键折叠，所以折叠提到第一张，见「同系列」。

## A+ 顺序（AH-GC1）

M1 开场 → M2 360° 前轮 → M3 手刹（两个一级差异各占一块）→ M4 折叠 3 步 → M5 手柄 → M6 球包兼容 → M7 配件轮播（3 张，每张 2 个配件）→ M8 尺寸图。

## 这个品类的固定做法

- **配件**：副图用一张配件汇总图（控制台俯拍 + 一圈引线）；A+ 用轮播，配对方式：手机支架 + 储物格、杯口 + 饮料架、伞架 + 伞收纳架。
- **尺寸图**：展开和折叠尺寸（L x W x H）、轮径、净重；brief 里 `product.foldable` 填 true；折叠尺寸不含前轮时注明 `without front wheel`。
- **不随货物品**：球包、球、伞、手机、饮料、记分卡，出现就标 Not included。
- **锁定类部件**：手刹翻转 180° 扣住锁定，动词用 flip / lock / flip back。`banned_verbs`：release、squeeze、hold。
- **常见禁用说法**（按本款实物再核）：one-click fold（GC1 不是）、dual brake（GC1 只锁右后轮）、all-terrain、fits all bags、测距仪磁吸、网兜、储物袋（GC1 没有）。
- **竞品参考**：Tivor、findway、Caddytek（EZ / Lite）、EASEGO 等，见 GC1 表「竞品图片参考」。

## 同系列多款（共用图片）

同一系列第二款起（如 AH-GC2 参照 AH-GC1）：

- 在同一个表格文件里用 `+sheet-copy` 复制已完成款的「图片需求」「A+ 需求」，改名为「<型号> 图片需求」等，再逐行改写；格式、合并、行高、列宽跟着复制。
- 先对比两款部件（零件表、样品照片、讲解视频），分三档写在最后一列「和 <首款> 共用」：
  1. **直接用同一张图**：只限同一个零件的特写（如两款共用的伞架、刹车杆）；外观不同的整车、车架颜色不同的画面不能共用；拿不准是否同一零件就写“待确认”。
  2. **同版式、同一次拍摄**：文案、版式、场景、模特、灯光沿用首款，只换本款实物重拍。
  3. **本款独有**：新写需求。
- 能共用的文案直接沿用首款原句（两款并排时信息统一）；本款参数、结构不同的地方必须改。
- 一级差异不同，图位顺序跟着本款调整，在「顺序依据」写明和五点顺序的差别。
- 我方参考图优先从本款讲解视频按时间点截帧（`ffmpeg -ss 时间 -frames:v 1`），截完逐张看，画面糊或不对就换时间点。

这一节不只适用于推车，其他品类做同系列时也照这个做。
