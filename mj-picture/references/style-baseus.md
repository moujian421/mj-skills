## 品牌通用规律

- **副图全部是竖图 1200×1500（4:5）**，6 款 51 张副图里除了主图和颜色变体，几乎没有正方形。
- **每个产品一套固定色调，整套副图 + A+ 统一**：FC11 冰蓝白、AM52 黑底 + 橙色手机、XC1 黑金橙暖光、MC2 奶油米色、充电头深蓝紫、扩展坞浅蓝灰。品牌层面没有统一主色，统一的是"一款一个色调"。
- **标题顶部居中、一到两行、整句一个颜色**（白字压深底或深灰字压浅底），没有描边和倾斜。强调只在小卡里给数字或关键词换品牌蓝（FC11「Charge **4** Devices」「**45W** High-Speed Output」）。
- **数字做法：超大数字当背景或主视觉**。AM52「45W」荧光绿大字横跨画面、XC1「IP66」「40hr」、MC2「55hr」「IP67」、充电头「43% Smaller」都是数字比商品还大，商品压在数字前面。
- **数据都带"实测对象 + 时间 + 结果"**：「30 mins | iPhone 17 Pro 67%」「20-Min Charge for iPhone 17 Pro 50%」「Charge an iPhone 17 Pro Max to 50% 34 min」，底部一行灰色脚注「Data sourced from the Baseus Lab; results may vary due to environmental factors.」。
- **对比图只比泛称**：「Others」「Other Wireless Charger」「Other mainstream power bank / The Industry Standard」，都附 Baseus Lab 脚注。
- **场景人物是棚拍质感的欧美年轻模特**，光线干净，商品在手里或桌面上清楚可见。
- **A+ 开头常用 2 张拼成一张开场**：第 1 张大场景 / 产品大图 + 品牌口号，第 2 张卖点总览（bento 卡片格），后面每个卖点一张。
- **手机端 A+ 基本整套重做**（6 款都有单独的 600×450 手机图），详见后面「手机端 A+」一节。

## 充电宝（B0GXDYN4J9、B0GYD3426W）

**副图顺序**
- FC11：主图（手握）→ 45W 快充 → 20000mAh 容量 + 生活场景 → 尺寸 / 便携 → NTC 温控安全 → 双自带线 → 四口同充 → 四格生活场景 → 黑色变体 → 黑色手握。
- AM52：主图（吸在手机背面）→ Qi2.2 认证 → Qi2.2 25W 速度 → 45W 有线 → 热成像对比 → 散热结构 → 双设备同充 → 磁吸力 13N → 容量 + 人物 → 兼容性。
- 共同顺序：**速度 → 容量 → 体积 / 便携 → 安全温控 → 线 / 口 / 同充 → 场景 / 兼容**。

**版式**：标题顶部居中，中间大图，底部一条数据带。FC11 用浅色"白色圆角卡"做拼格（g04 尺寸 + 屏幕两格、g06 输入 / 输出两格、g08 四格场景）；AM52 用黑底 + 深灰圆角卡，数据卡压在图片下部。

**标题写法**（实际文案）
- 参数句：「45W High-Speed Charging」「Qi2.2 Certified 25W Fast Wireless Power Bank」「13N Strong Magnetic Connection」「10,000mAh All-Day Power」。
- 参数 + 好处两行：「20000mAh / Compact & Travel-Ready」「Built-in Two-Way USB-C Cable」+ 副标题「Fast Charge & Recharge, No Extra Cables Needed.」。
- 对仗句：「Cool & Safe System」「Superior Cooling, Superior Safety」「Stay Powered, Stay Free」。

**配色**：FC11 冰蓝白渐变（安全图用冰雪 + 透明盾牌「NTC」）；AM52 黑底 + 暖木桌面 + 橙色手机，数字用荧光绿（充电进度、45W）。

**数字可视化**
- 充电速度：「⚡30 mins | iPhone 17 Pro ▬▬ 67%」绿色进度条，两台设备上下两行。
- 次数：「3.4 Charges iPhone 17 Pro / 2.5 Charges Samsung S25 Ultra」，数字放大成品牌蓝。
- 对比：AM52「34 min」（白卡）vs「1h06 min Other Wireless Charger」（灰卡）；热成像三联「36.2°C / 40.3°C / 48°C」分别标 AM52、Other mainstream power bank、The Industry Standard。
- 尺寸：细尺寸线 + 「4.3×2.6×1.2 in」；FC11 A+ 用一副扑克牌做体积参照。
- 端口：四个小圆角标签「USB-C1 Cable 45W Output /30W Input」「USB-A Port 33W Output」。

**场景和人物**：咖啡桌、机场候机、露营、书桌；FC11 是浅色室内，AM52 是暖色暗调（咖啡馆、驼色大衣）。

**A+ 顺序**
- FC11：开场（双人模特 +「Power Your Life, Simplified」）→ bento 卖点总览 → 轻便 → 容量 → 安全 → 双线 → 45W → 四口同充 → 30W 回充 → Why Choose Baseus（Baseus vs Others 清单）→ 兼容性 → 机场 → 露营 → 书桌 → 售后卡。
- AM52：「PICOGO」大字水印开场 → 「Qi2.2 25W」大字 → Qi2.2 / Qi2 / Qi 三代规格表 → bento 总览 → 兼容性 → 25W → 45W → 30W 回充 → 认证证书 → 散热 → 热成像 → 口袋场景 → 质感三格 → 场景「Travel Companion」「Daily Commute」「Work Booster」。

**主图**：FC11 主图是手握商品（白底），AM52 主图把充电宝吸在一台橙色 iPhone 背面（手机作道具，展示磁吸用法）。

## 开放式耳机（B0FMRPKN3G、B0GY89X4PJ）

**副图顺序**
- XC1：主图 → 品牌开场（人物 + 合作品牌 logo 排）→ 发声单元 → 佩戴舒适 → 通话降噪 → IP66 → 40hr 续航 → 白 / 银 / 紫三张颜色变体。
- MC2：主图 → 佩戴舒适（CloudComfort 2.0）→ Hi-Res 音质 → 名人背书 → 单元结构 → 55hr 续航 → IP67 → 通话 → 通透（街景）→ 耳垫安装说明。
- 共同顺序：**品牌 / 音质 → 佩戴舒适 → 通话 → 防水 → 续航 → 颜色或安装说明**。

**版式**：和充电宝相反，**标题放在下三分之一**，压在人物照或产品图上，下面跟两行小字说明 + 一排小图标（「SuperBass 3.0」「LDAC」「Hi-Res」）。上面大半张留给人物或产品。

**标题写法**（实际文案）
- 感受句为主：「Clip On, Feel the Rhythm」「Feel Every Beat in Hi-Res」「Stay Aware. Stay in the Moment.」「Keep Moving, Never Drop」。
- 参数句用在防水、续航、通话：「IP67 Waterproof」「Up to 55 Hours of Playtime」「4-Mic AI Clear Calls」「Voice-Shielding AI for Clear Calls」。
- 技术命名：「Hybrid 2-Way Sound Engine」「CloudComfort 2.0 Wrap-Around Cushioning」「Gentle-Hug Adaptive Ring Joint」。

**配色**：XC1 黑底 + 橙金暖光（演唱会、夕阳、城市夜景）；MC2 奶油米色 + 云朵、柔光（睡眠、瑜伽、网球）。一款只用一个色调，人物服装也配色调。

**数字可视化**
- 背景大字：「IP66」「IP67」「40hr」「55hr」半透明立体大字，耳机压在前面。
- 快充公式：「10 min = 2.5 hr」+ BRC 图标。
- 舒适数据：「+62% Enhanced Cushioning Volume」「10,000+ Bends proven for resilience」「+16% Extended C-ring flexibility」，放进深色或米色小圆角卡。
- 通话：「5 m/s Wind noise resistance」「75 dB(A) Noise-proof call clarity」。
- 尺码：三个耳垫并排「XL: 0.08 in / L: 0.10 in / M: 0.12 in」+ 一根「Tighter Fit → Looser Fit」箭头。

**场景和人物**：人物占比最高的大类，几乎每张都有人：跳舞、滑雪、网球、街头通话、睡觉。耳机在人物耳朵上，靠特写或局部放大小卡补细节。

**A+ 顺序**
- XC1：开场（「Born to inspire」+ logo 排 + 6 格卖点卡）→ Sound by Bose → Dolby 360° → 单元爆炸图 → 音效算法 → 定向声场 → 防掉 → 气垫舒适 → 耳挂结构 → IP66 → 通话结构 → 街头通话 → 多点连接 → App → 外观 → 续航。
- MC2：睡眠场景 + CNET / SGS / TÜV 奖章 → 口号 + 6 图标卖点 → 舒适 → 三种耳垫 → 轻 5.1g → C 形耳挂 → 运动不掉 → Hi-Res → 单元 → 空间音频 → 定向声场 → App → AI 助手 → 续航 → IP67 → 通话。
- 规律：**先音质 / 品牌背书，再舒适，再运动、防水、通话、App、续航**。

**主图**：两款都是白底、两只耳机一正一侧，无文字（「Sound by Bose」是印在机身上的）。颜色变体单独放最后几张，同角度只换色。

## 充电器与扩展坞（B0DYHXNTV2、B0CJBSS7Z9）

**副图顺序**
- 100W 充电头：主图 → 100W 笔电快充 → 3 口同充 → 散热 → 兼容性 → 体积 + 折叠插脚 → 黑色变体。
- 10 合 1 扩展坞：主图 → 接口总览（10-in-1 Expansion）→ 4K@120Hz → Windows 显示模式 → macOS 显示模式 → 10Gbps 传输 → 锁屏键 → PD 100W → 银色变体。
- 共同顺序：**核心参数（功率 / 接口数）→ 主要用途 → 技术或限制说明 → 兼容 / 便携 → 颜色**。

**版式**
- 充电头：深蓝紫渐变底，顶部白字标题，下面一到两张圆角图片卡。
- 扩展坞：浅灰白底，标题放在左上或右上（不居中），场景照占满，文字压在空白处；接口总览用细引线 + 接口名 + 括号参数「HDMI (4K@120Hz)」「USB-C (10Gbps)」。

**标题写法**（实际文案）：「100W Laptop Fast Charging」「3-in-1 Multiport. Multitask.」「Effective Temperature Drop」「Travel-Friendly Portability」「Blazing-Fast Data Transfer」「Convenient Screen-Lock Button」「Display Modes for Windows / MacOS」。参数和功能名就是标题。

**配色**：充电头整套深蓝紫 + 白色机身 + 黄色接口高亮；扩展坞浅蓝灰 + 深灰机身 + 橙色线头，数字用品牌蓝。

**数字可视化**
- 笔电充电：「Charge a MacBook Pro 16" (M4) to 100% in 1.77 hrs」+ 蓝色进度线。
- 手机充电：两格「20-Min Charge for iPhone 17 Pro 50%」「30-Min Charge for Samsung Galaxy S23 56%」。
- 功率分配：线框画充电头正面，每口一根黄色引线标「100W」「70W + 30W」「70W + 22.5W」，分 Single-Port / Dual-Port 两张。
- 体积：「43% Smaller」大字，自家充电头放在两个通用大充电头中间（不点名品牌）。
- 传输：「20s | 10Gbps USB3.2 Gen 2」（蓝卡）vs「50s | 5Gbps USB3.0」（灰框），「Time for transferring a 20G file」。
- 显示模式：A/B/C 小屏幕示意 + 分辨率，macOS 不支持的一格打红叉。

**限制说明**：直接写进图里的小字——「*Only the HDMI1 port in single display supports 4K@120Hz clarity」「Power adapter and input cable are not included」「Press once for Windows systems, or twice for MacOS」「The USB-A and USB-C data ports do not support charging」。

**场景和人物**：充电头几乎无人，只有手捏折叠插脚；扩展坞是桌面办公、沙发办公，人物侧面专注，扩展坞在桌面小比例出现。

**A+ 顺序**
- 充电头：开场（光速线条 +「Versatile & Efficient」）→ bento 总览（100W / 3 in 1 / Portable / BCT / Reliable）→ 100W 笔电 → 手机快充 → 3 口同充 → 散热 → BCT 温控 → 便携 → 体积 → 认证 → 单口分配 → 双口分配 → At Work / At Home / On the Go 三格。
- 扩展坞：品牌故事卡 + 售后卡 → 开场（双屏办公 + 6 图标）→ 接口总览 → 4K@120Hz → 双屏模式 → 10Gbps → 透传充电 → 锁屏键 → 便携 → 质感 → 兼容表（附双屏 4K 条件）→ 设备兼容卡 →「Here to Help!」故障排查卡（Screen Flickering / Dock Fails to Power Up / HDMI Output Not Functioning / PD Charging Glitches）。

**主图**：充电头主图白底 3/4 斜角，插脚旁画了一个旋转箭头图示；扩展坞主图摆了 HDMI 线、SD 卡、U 盘、网线插头等不随货道具，HDMI 插头印「4K」，用道具直接展示接口用途。

## 手机端 A+（600×450）

6 款都做了单独的手机版（600×450，充电头有 1 张 1200×900 高清版），不是把电脑端 1464×600 直接缩放。和电脑端对比：

**1. 版式：横向"左文右图"改成"上文下图"**
- 电脑端标题多在左侧、商品在右侧；手机端把标题**移到顶部居中**，商品或场景放在下方。例：FC11 电脑端「Power Your Life, Simplified」在左、模特在右 → 手机端标题一行压在顶部、双人模特在下；充电头「Effective Temperature Drop」「Travel-Friendly Portability」同样从左侧移到顶部居中。
- 电脑端横排 3 格（FC11「Dual Built-in USB-C Cables」三格、充电头「3 in 1 Multiport」两格）→ 手机端改成 1 大 + 2 小的 2×2 或上下排列。
- 电脑端 bento 总览（FC11 6 格、AM52 6 格、充电头 5 格）→ 手机端重新排成 2 列，每格更大。
- 耳机和扩展坞的人物图：电脑端标题压在人物左侧空白 → 手机端标题压在图片下三分之一（XC1「Keep Moving, Never Drop」、MC2「Stable Fit As You Move」）或左上角，人物放大裁切。

**2. 主标题：一行 2–5 个词，最多 2 行**
- 单行：「Enhanced Safety」「Dual Built-in USB-C Cables」「Charge 4 Devices Simultaneously」「Smart Temperature Control」「Screen-Lock Button」。
- 两行：「Lightweight Charging / You Can Carry Anywhere」「20000mAh / Compact & Travel-Ready」「Elegant Design with / Premium Quality」。
- 电脑端是两行的标题，手机端常合成一行（FC11「45W High-Speed Charging」「Charge 4 Devices Simultaneously」）。

**3. 字号（按 375px 显示宽度估算）**
- 主标题约 18–24px（原图 600 宽里约 30–38px），粗体，整句一色。
- 副标题约 11–13px，一到两行。
- 卡片内标签约 9–11px；脚注约 5–6px，基本看不清，只作合规说明。
- 对比：同一张电脑端 1464 宽图缩到 375 宽时，标题只有约 12–15px，说明文字 5–7px，所以单独做手机版能把标题放大约 1.5 倍。

**4. 文字删减：多数保留原文，耳机类保留长段落**
- 充电宝、充电头基本保留电脑端的标题和副标题，只删掉部分图标说明（FC11「Airline-Approved」手机版只留标题 + 一个图标）。
- 耳机两款手机版**保留了整段 3–6 行说明文字**（XC1「360° Sound Reality」「Directional Sound, Private Listening」、MC2「Sound That Feels Alive」），375 宽下约 9–10px，偏小，是这套图里最难读的部分。
- MC2 把电脑端第 1、2 张（睡眠场景 + 标题 / 图标排）在手机端重新分配：标题 + 奖章放第 1 张，6 个卖点图标 + 脚注放第 2 张。

**5. 图片裁切：商品和人物放大**
- 4:3 画幅比 2.44:1 更高，商品占画面比例明显变大（AM52「Qi2.2 25W」、充电头「Compact Design 43% Smaller」）。
- 人物图改成近景，裁掉左右背景；扩展坞「Mini & Compact」把人物 + 背包裁成半身。
- 数据卡（「34 min / 1h06 min」「5 m/s / 75 dB(A)」「20s / 50s」）在手机版放大成独立一行。

**6. 顺序和内容基本跟电脑端一一对应**
- 手机版和电脑版张数、顺序基本一致，一张电脑图对应一张手机图，只改版式，不新增卖点。
- 例外是删减：扩展坞「Compatibility & Media Display」电脑端表格旁有三行「Conditions for Achieving Dual-screen 4K」，手机端删掉这三行只留表格。

## 和 Anker、UGREEN 的区别

（Anker、UGREEN 规律见 `style-anker.md`、`style-ugreen.md`）

1. **底色和色调**：Anker 几乎全浅色、一个品牌蓝；UGREEN 浅色为主、品牌绿做小标签；Baseus 每款商品自定一个色调，深色（AM52 黑、XC1 黑金、充电头深蓝紫）和浅色（FC11 冰蓝、MC2 米色）都有，更像"一款一个主题"。
2. **数字的分量**：Anker 大数字多放在底部白卡；UGREEN 用浅色水印数字；Baseus 把数字做成画面主体（荧光绿「45W」、立体「IP66」「55hr」），商品压在数字前面，冲击力更强。
3. **人物和场景**：Anker、UGREEN 人物少、偏居家办公；Baseus 人物多且是棚拍模特，耳机类几乎每张都有人，场景偏时尚生活方式。
4. **手机端**：Baseus 6 款都单独做了 600×450 手机版，标题移到顶部居中、多格改两列；Anker、UGREEN 的参考里没有记录单独的手机版做法。
5. **对比图**：三家都只比泛称；Baseus 用得最多（热成像三联、充电时长、传输时间、「Why Choose Baseus」清单），每张都带 Baseus Lab 脚注。

## 可以怎么借鉴（按需挑选）

- 可以给每个商品定一个色调（底色 + 一个强调色），副图和 A+ 统一用，不必所有商品同一套颜色。
- 可以把最核心的一个参数做成画面主体大字（功率、防水等级、续航），商品压在数字前面。
- 充电速度可以写成"测试设备 + 时间 + 百分比 + 进度条"，底部一行脚注写测试来源。
- A+ 开头可以考虑"开场大图 + bento 卖点总览"两张连着放，后面一个卖点一张。
- 耳机、穿戴类可以考虑把标题放在下三分之一压在人物图上，上面留给人物；配件、充电类标题放顶部居中。
- 手机端 A+ 可以单独做 600×450：标题顶部居中、一行 2–5 个词、最多两行，在 375px 宽下约 18–24px；横排三格可以改成 2×2 或上下排列。
- 手机端可以删掉长段说明，只留标题 + 一行副标题 + 一个数据卡；Baseus 耳机手机端保留了整段文字，显示约 9–10px。
- 有使用限制（接口不能充电、需另购适配器、某系统不支持）可以用一行小字写在相关图下方，显示模式可以用小屏幕示意 + 红叉。
- 体积对比可以用"自家商品 + 两个不点名的通用大号商品"做参照，配「xx% Smaller」。
- 对比图如果要做，只比泛称 Others / Other xx，并且必须有实测或公开数据作依据，标在脚注里。
- 颜色变体可以放最后几张副图，和主图同角度只换颜色。
