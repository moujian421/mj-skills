# A+ 规则

字数上限见 [copy-rules.md](copy-rules.md)，手机端各品牌做法见 [aplus-mobile.md](aplus-mobile.md)，例子见 [examples-gc1.md](examples-gc1.md)。

## 尺寸

Premium A+ 每个模块有两个尺寸：手机端 600×450 px、电脑端 1464×600 px（以后台实际模板为准），按 M1、M2… 顺序上传。优先按手机端 600×450 设计，电脑端在此基础上改版式；电脑端文案可以按需多放一些字，但不用每个模块都单独写一版。

## 表结构

在副图表的基础上加：类型、和副图的关系、alt text；可选加「电脑端文案（可选）」，只在电脑端要多写几个字时填，不填就和手机端一样。不加“上线安排”列。

## 和副图的分工

A+ = 副图卖点的放大版（同样卖点，画幅更大、步骤和细节更多）+ A+ 独有内容（开场大图、配件细节、结构 / 校正 / 包装清单、自家对比表）。“和副图的关系”列写明是哪张副图的放大版，或 A+ 独有。

自家对比表只比自有型号，对比款未上线前先不发该模块。对比行按“核心功能 → 使用体验 → 规格参数”分组，用 ✅ / — 标记，每一行都要有依据；本款最强的行放前面。

## 模块默认顺序

没有更好的 A+ 竞品统计依据时用：

1. 开场：品牌 + 品名 + 主要卖点；
2. 一级差异放大版（可配痛点对比图）：**每个一级差异单独一块**，不合并成左右分屏；次要卖点可以两三个合并成一块分屏。主标题直接写功能名，不用要买家自己猜的概括说法；
3. 刚需问题的步骤放大版；
4. 使用体验；配件多（≥4 个）时用轮播；
5. 多场景用途；
6. 尺寸规格 / 包装清单；
7. 自家型号对比表（有对比款时）。

收尾不写“立即购买”“限时”这类催单文案。

## 各类型文案

| 类型（brief 里的 type） | 文案怎么放 |
|---|---|
| 开场 `aplus_open` | 见下方「开场」 |
| 配件轮播 `aplus_carousel`（配件 ≥4 个时用；配件少的品类改用场景或细节特写模块） | Premium 图片轮播模块：多张图只占 1 个模块（最多 8 张，每张 1464×600，手机端以后台模板为准）。每张讲 2 个配件，左右各一个，按位置或用途配对；每个配件上方用配件名当主标题（一张两个主标题，同字号、同高度对齐；手机端每半约 260 px，可排两行，字号不低于 24 px），不放副标题、小文案和标签；每张一条 alt text；全部张用同一版式、底色和字号 |
| 宫格 `aplus_grid` | 主标题 + 副标题；每格一个短标签；手机端改成上方标题 + 下方 3×2 宫格。配件优先用轮播，宫格只在模块数有空余、要一屏总览时用 |
| 功能 / 步骤 / 尺寸 / 场景 | 同副图对应类型，可以同时有小文案和图标 |

## 开场

- **画面**：场景 + 整机：真实使用场景里，整机完整、清楚可见；也可以用白底整机。不是只放场景氛围、看不清商品的图。
- **主标题**：品牌 + 品名（买家搜索的核心关键词）+ 1–2 个主要卖点（取一级差异；太长时只留一个或不加）。
- **分行**：两行时**第一行只放品牌**，第二行放品名 + 卖点。
- **品牌字要醒目**：字号约为第二行的 1.5–2 倍，可以用品牌 Logo 字体；效果跟品类调性走（器械、户外可以用金属、渐变、投影；地垫、居家类偏简洁）。在「画面与构图」写明字体和效果。
- **副标题**：讲产品体验或功能，并结合使用场景，≤38 字符。
- **字数**：电脑端 1464×600 品牌一行 + 品名卖点一行。手机端 600×450 品牌一行（粗体约 56–64 px）；第二行粗体约 34 px、≤500 px（约 ≤29 字符）。太长时依次：只留一个卖点 → 不加卖点只留品名 → 两个卖点都要时拆成两行、每行 ≤29 字符。不要把第二行字号降到 24 px 以下。

## 手机端版式

参考品牌的热卖款都为手机端单独做了一套 600×450 图并重新排版，不是电脑端缩小或裁切。每块先写手机端版式，常用“上文字带 + 下图片”；电脑端一块信息太多时，手机端可以拆成 2–3 块；总览宫格改成 2×3 / 3×3；纯氛围图可以不放字，标题写进 A+ 模块的文字栏。交付前把 600×450 稿缩到 375 px 宽看一遍。

## alt text【底线】

每张 A+ 图必须写：≤100 字符，描述画面，不堆关键词，画面里的文字要能在 alt text 里读到。

## A+ 额外禁止项【底线】

A+ 规则比副图更严，下面这些不能出现在 A+ 图片或文字栏里（写需求前按 Seller Central 最新的 A+ 指南再核一次）：

- 买家评论、评价截图、买家原话或个人推荐语；
- 价格、折扣、促销、限时、库存紧张、节日活动等会过期的说法；
- 保修、退换、退款、`Guarantee` 类承诺，以及包邮、配送时效；
- 外部网址、二维码、联系方式、店铺或卖家名称；
- 竞品品牌、和别家比较的说法。

认证、专利、测试数据可以放，但必须有证书或报告，「依据」写编号。
