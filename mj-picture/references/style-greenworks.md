## 1. 整体

- 一个品牌色贯穿全套：荧光绿 + 深灰 / 黑，商品本身也是这两色。
- 字体是全大写粗体无衬线，压缩感强，工业风。
- 主体是实拍：手持工具在干活的近景（装层板、拧螺丝），人物只出现手和手臂，戴手表、穿工装衬衫。

规律：
- 卖点图都是“上实拍 + 底部绿色文字带”，标题两行：第一行功能名（大），第二行一句用途（小）。
- 尺寸、扭矩、转速直接写进标题，数字字号最大。
- 电池和充电头被当作独立卖点（USB-C 充电头、电池当充电宝），各占一到两张。
- 后半段讲平台：电池通用、保修、200+ 产品生态。

## 5. 手机端 A+（600×450，9 块）

- 有单独的手机版，块数和顺序与电脑端一一对应。
- 多数是把电脑端照片裁成 4:3，标题直接叠在照片上方或下方空白处，字号放大（375px 宽下标题约 20–24px，清晰）。
- `INCLUDES` 和平台四宫格按 4:3 重新排：配件格从横排改成 2×2，四宫格改成 2×2。
- 手机端第 1 块的参数卡写的是 `TORQUE 400 IN-LBS` / `2 SPEEDS 450 / 2000 RPM` / `BIT SIZE 1/2 INCH`，与电脑端 A+、副图和标题的 `1900 IN-LBS` / `3,600 RPM` / `1/4" HEX` 不同（2026-10-23 抓取时如此）。

## 可以怎么借鉴（按需挑选）

- 工具类商品可以用“上方实拍干活近景 + 底部品牌色文字带”的固定版式，全套统一。
- 核心参数可以做成三格数据带（扭矩、转速、尺寸），大数字 + 小单位。
- 尺寸卖点可以直接放在真实使用的狭窄场景里拍，标题写尺寸数字。
- 套装商品可以单独一张 `INCLUDES` 图：主机大格 + 配件小格，每格写名称。
- 平台型商品可以在后半段讲电池通用、保修年限和产品生态。
- 手机端和电脑端是两套图，参数可以分别核对一遍。
