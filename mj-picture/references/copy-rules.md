# 文案规则

字数、像素、禁用词、层级数量都由 `scripts/brief_lint.py` 检查，这里写规则本身和脚本判断不了的部分。例子见 [examples-gc1.md](examples-gc1.md)。

本文件的规则都是默认做法（标【底线】的除外）：有理由不按时，在「依据」或「禁用 / 注意」写一句理由。

## 按图的类型定文案

层级按需要选，不是每张图都要主标题、副标题、小文案、图标齐全。没有新信息的层级就不放，格子填“—”。

**副图默认只放主标题 + 副标题。** 小文案和图标都是可选层，有新信息才放：

- 一张副图原则上不同时放满四层。四层都有时，删掉和其他层重复最多的那一层；讲出本张图核心好处的那层要留。
- 图标可以是小圆特写图的部件或状态标签，也可以是线条图标（适合防滑、防水、静音这类看不见的卖点）。每张副图 0–3 个，跟着构图走，不为凑数硬加。
- A+ 画幅大，可以同时有小文案和图标，不按副图的比例要求。

| 图的类型（brief 里的 type） | 文案怎么放 |
|---|---|
| 主图 `main` | 【底线】不放任何文字 |
| 功能图 `feature`（讲一个卖点） | 主标题放这个卖点最抓人的一面（功能名、参数或好处都可以）；副标题补主标题没说的好处或用法；小文案补操作细节，和副标题说的是同一件事就不放；图标可作小圆特写图的部件 / 状态标签 |
| 步骤图 `steps`（折叠、安装） | 主标题 + 步骤短句，步骤编号放画面里 |
| 配件汇总图 `accessory`（一圈引线标注） | 随货配件 ≥4 个时才单独做一张；少于 4 个就并进别的图，没有配件就不做。不放图标；副标题写成清单，随货配置全部列出，不能漏项【底线】；小文案可补一层用途或删掉 |
| 尺寸规格图 `dimension` | 主标题可以不放；外形尺寸（可折叠的写展开和折叠）、这个品类买家最关心的尺寸（如地垫厚度、推车轮径）、净重都标在标线 / 引线 / 图标旁，不计字数，和工厂尺寸图数字一致；小文案补材质等非数字信息 |
| 场景图 `scene` | 不放文案，或只放一句主标题 |
| 痛点对比图 `pain`（没有它 / 有了它） | 主标题点出解决的问题；两侧各一个 2–4 词短标签；【底线】“没有它”一侧用通用场景或 Others，不出现竞品品牌、不夸大；只在差评或竞品评论里确有这个痛点时用，「依据」写出处 |
| 多场景用途图 `multi`（2–4 格） | 主标题概括用途；每格一个 ≤4 词场景短标签；每个场景都要是说明书或实测能做到的 |

A+ 各类型见 [aplus.md](aplus.md)。

**清单式副标题**（配件汇总图）：不受单句副标题字数上限限制，按清单项控制：每项 ≤4 个单词、≤22 字符，每项单独一行（格子内换行），不加点或其他分隔符。同一个部件只列一次，名字按买家最能理解的功能叫。

## 字数上限

默认单行。上限按手机上能看清的字号实测 Arial 字宽，再留约 15% 余量；像素测量是为了保证手机上看得清，排两行时每行也按它量。

**副图 1200×1500**（两侧各留 80 px，可用 1040 px；手机上约缩到 0.31 倍）：

| 层级 | 画布字号 | 手机上约 | 单行上限 | 像素上限 |
|---|---|---|---|---|
| 主标题 | 粗体 72 px | 22 px | ≤25 字符 | ≤880 px |
| 副标题 | 48 px | 15 px | ≤42 字符 | ≤915 px |
| 小文案 | 40 px | 12.5 px | ≤52 字符 | ≤935 px |
| 图标短语 | 36 px | 11 px | ≤22 字符，≤4 个单词，每张 0–2 个，左右对称 | — |

**A+ 手机端 600×450**（两侧各留 40 px，可用 520 px；手机上约缩到 0.625 倍）：

| 层级 | 画布字号 | 手机上约 | 单行上限 | 像素上限 |
|---|---|---|---|---|
| 主标题 | 粗体 40 px | 25 px | ≤22 字符 | ≤440 px |
| 副标题 | 26 px | 16 px | ≤38 字符 | ≤460 px |
| 小文案 | 20 px | 12.5 px | ≤50 字符 | ≤470 px |
| 宫格 / 图标标签 | 18 px | 11 px | ≤20 字符 | — |

- 上面两张表是没有指定参考品牌时的默认值。**参照某个品牌的风格时**，主标题 / 副标题 / 最小字的字号、单行字数、行数、大小写、对齐和位置都按那个品牌的实测值写进「画面与构图」，不取各品牌的平均值（实测见 [typography-stats.md](typography-stats.md) 和各品牌文件末尾）；brief 里填 `brand_style`，脚本对超限只提醒。
- **排两行**：设计上需要时可以排两行（格子里用换行写出断行位置），每行仍在上表像素上限内，总长按团队标准（2026-06-30）：主标题 3–6 词 ≤32 字符、副标题 4–8 词 ≤50、小文案 4–10 词 ≤65。
- **尺寸和重量标注不计字数**：分开标在标线、引线或图标旁，不为凑上限拆行或删注释。字数列写“尺寸 / 重量标注（不计字数）”。写法统一：`L 55.6 x W 29.1 x H 46.1 in (141.3 x 73.8 x 117.0 cm)`、`Net weight: 18.7 lb (8.5 kg)`，英寸 / 磅在前，公制在括号里。
- 字数列格式 `主 4/23｜副 5/33｜小 9/53｜图标 2/11、2/14`（词数/字符数），清单式副标题写“副 N 项清单”。由脚本生成，每次改文案都重跑。

## 层级之间不重复

主标题说过的功能或参数，副标题不再重复。副标题补：这个功能带来的好处、怎么用（操作方式、切换方法）、主标题没说的参数或范围。小文案再往下补一层（操作细节、适用场景、使用边界）。

**副标题和小文案也不能传达重复信息。** 按意思判断，不只看用词：小文案只是把副标题的用法换个说法，或者说的是画面（小圆图、箭头、步骤编号）已经展示的操作，就删掉，格子填“—”，中文释义写“小：无”（可在括号里注明由画面哪部分展示）。

删不删的判断：遮住小文案只看主标题、副标题和画面，买家少知道了什么？说不出来就删。

图标短语可以和主标题、副标题用词重复：图标多是小圆特写图的状态或部件标签。

脚本只能查出字面重复；同义说法、复述画面这类重复由 Claude 逐张判断。

## 功能 → 好处 → 场景

写功能图前，先给每个卖点列一行：部件或参数 → 买家因此得到什么 → 在什么场景下用到。三样里挑最抓人的放主标题（结构类商品常放部件或参数，体验类商品如地垫常直接放好处），其余放副标题和小文案，不重复。好处要具体到动作或结果（`Stops on downhill slopes`），不写空泛的 `Peace of mind`、`Better experience`。列不出好处的卖点，并到别的图里或往后放。

## 动词和实物操作一致【底线】

动词按说明书或视频里的实际操作写。扣住就锁定的部件用 flip / lock / flip back，不用 release / squeeze / hold，这些词会让人以为要一直捏住。拿不准操作方式时先看说明书或视频，再问用户。有锁定类部件时，把禁用动词写进 `product.banned_verbs`。

## 中文释义

逐句对应英文，不增不减；不放的层级写“无”。每个层级单独一行（主：… / 副：… / 小：… / 图标：…），不用“｜”连在一行。
