## 品牌通用规律

- **暖中性色做底**：沙色、米色、焦糖色渐变，强调色是金棕/铜色。不用冷蓝灰大底。科技感靠局部光效做（吸力/激光用蓝光，热风/烘干用橙光），不靠整张冷色调。
- **品牌横幅用黑金渐变**：A+ 品牌模块（代言人 + 产品陈列台）是黑到金的舞台光，和副图的浅暖色形成反差。
- **字体**：无衬线、粗体标题，字号克制；关键数字用斜体或金棕色单独放大，旁边配小号说明（如 `100% Particle Pickup`）。
- **数据都带脚注**：每个百分比、Pa、分钟数下面有一行灰色小字，说明来自自家实验室测试、实际可能不同。
- **对比只比 Others**：对比卡左边写自家型号（亮色、打勾），右边写 Others（灰色、降饱和），中间一个 VS 圆标。
- **A+ 开头先放品牌模块**：清洁类全部共用一套（代言人横幅、销量第一证书、生活方式图、宠物图、服务政策卡、奖项与媒体墙），之后才放单品内容。D30 Ultra CE 的 A+ 只有这 7 块品牌模块，没有单品内容。
- **尾图惯例**：包装清单（白底网格 + 每件配件名 × 数量），之后放另一个颜色或耗材图。

## 扫拖机器人

**副图顺序**（D30 Ultra CE，D20 Air Plus 类似）：吸力 → 贴边/边角 → 基站功能 → 拖布自清洁 → 防缠绕滚刷 → 地毯识别 → 导航避障 → 包装清单 → 另一颜色。先讲吸力和覆盖，再讲省事（基站），最后讲智能（导航/App）。

**版式**：
- 1500×1500 方图。底部约 15% 是焦糖色渐变标题条，白色粗体标题居中一行，没有副标题；上方 85% 是画面。三款机器人都这样，整组图一眼就能认出是同一套。
- 画面左上角放 1–2 组大数字 + 小标签，例如 `100% Particle Pickup`、`99% Hair Removal`、`0 in Edge Cleaning Gap`。
- 画面下半部常放一排圆角小卡：三张垃圾样本卡（Hair / Paper Scraps / Cat Litter），或四个功能图标卡（Auto Mop Drying 等），或两张对比卡（自家 vs Others）。

**标题写法**（短，偏口语）：`Max Suction for a Deeper Clean`、`Unreachable? Reached`、`Less Residue, Better Results`、`Simplify Your Post-Cleaning Routine`、`Tangle-Free Cleaning Guaranteed`。D20 更偏参数：`Flagship-Level 20,000Pa Suction Power`、`120-Day Hands-Free Dust Collection`。

**数字可视化**：
- 吸力数字做成立体字，由灰尘颗粒/垃圾堆成（`25,000Pa`、`20,000Pa`），机器在上方往下吸。
- 基站用剖面透视：清水箱是蓝色水体，污水/集尘可见。
- 集尘天数做成半透明大数字卡（`120 Days`）悬在基站上方。
- 续航/覆盖用橙色大数字（`150 min Runtime`、`1,900+ sq ft Coverage`），路径线用红/绿色区分低电回充和断点续扫。

**场景和人物**：暖光客厅、木地板、地毯；宠物（猫、狗）出现很多次；人物少，主要在地毯/儿童场景的 2×2 拼图里出现。导航图用蓝色扫描光束 + 障碍物（拖鞋、电线、玩具）。

**两款的差别**：D30 Ultra CE（高价）用米金色、白色机身、整体更素；D20 Air Plus（低价）用橙色强调、副图第二张左上放 `NO.1 Sales & Revenue` 徽章和第三方推荐章，更像促销图。

**A+**（D20 Air Plus）：开头横幅（型号 + 两句口号 `Stores it smart. Sucks it strong.`）→ 卖点总览拼格（bento 网格，6 个小格各配一句话）→ 之后每块讲一个卖点：左图右文或左文右图交替，浅灰白底，标题黑色粗体、正文 3–4 行小字、底部一排橙色数字或图标。比副图更浅、更白、更“说明书”。

**主图**：机器 + 基站白底，右下角放一部显示 App 图标的手机（D20 还有智能手表）。手机作道具，展示 App 控制。

## 洗地机

**副图顺序**（H12 PRO）：吸力 → 干湿垃圾/适用地面 → 自清洁烘干 → 贴边 → 自走助力 → 双水箱 → 配件清单 → 白底多角度（2 张）。G10 Pro：重污 → 双水箱 → 自走 → 贴边 → 续航 → 自清洁 → 吸力 → 白底多角度（2 张）。

**版式**：
- H12 PRO 用竖图 1125×1500（3:4），G10 Pro 用方图。
- 底部焦糖色标题条和机器人一样，但**多一行副标题**：标题粗体 + 下方一行细字。例如 `Powerful Suction for Flawless Clean` / `Stop pushing dirt around…`；`Self-Cleaning & Drying` / `Deep clean. Instantly dry.`。
- 白底多角度图：实物 + 半透明重影，表现躺平/后仰角度，没有文字。

**标题写法**：功能名 + 好处，偏直白：`Edge-to-Edge Cleaning`、`Sticky&Heavy Messes Killer`、`Wash & Vacuum in One Step`、`Up to 35mins Runtime`、`3min Fresh Water Self-clean`。

**数字可视化**：
- 吸力对比条：深色半透明卡，上条 `H12 Pro 16,000Pa`（长、金色）、下条 `Others 6,000Pa`（短、灰色）。
- 滚刷发蓝光，`16,000Pa` 蓝色立体字压在地面上。
- 水箱容量直接贴在机身上：`900mL Clean Water Tank`、`700mL Used Water Tank`。
- 续航用三颗胶囊标签并排（Quiet 35 / Standard 25 / Turbo 15 Mins）。
- 适用地面用四张材质小卡（Marble / Tile / Wood / Laminate）。

**场景和人物**：比机器人用人多。真人推机器在厨房/客厅走，常见同一画面左右两人对比（左边传统拖把或 Others 灰调，右边自家亮调）；儿童打翻零食、狗吃粮撒地，表现脏乱场景。干湿垃圾用酱汁、麦片、坚果、番茄酱摆成放射状。

**和机器人的差别**：多了操作步骤（4 步走：加水 → 拖地 → 一键自清洁 → 倒污水）、维护和 Before/After；人物和手部动作更多；副图有副标题；A+ 里出现深黑底和 FAQ 模块，整体比机器人杂一些。

**A+**（H12 PRO）：品牌模块 6 块（代言人横幅、其他新品宣传、专利数、家庭用户数、服务政策、北美家庭适配）→ 单品横幅 `Your First Vacuum Mop` → 畅销背书（用户数、媒体推荐、奖项）→ 4 步使用流程（带编号的箭头标签条）→ 干湿垃圾 → 原理三格卡 → 一键自清洁（圆形放大镜指向按键）→ 热风烘干 Before/After → 全能地面 → 语音/模式说明 → 贴边对比。G10 Pro 另有续航场景（户型等距图 + 三档时间）、四模式竖条拼图、LED 屏说明（胶囊标签）、FAQ（棕底，问答 5 条）。

**主图**：H12 PRO 是机器 + 随货配件（清洁刷、清洁液、滤网、备用滚刷）白底，可参考。G10 Pro 左上角放了三块地板材质样片，作道具，展示适用地面。

## 个护（吹风机 / 造型器）

**副图顺序**：
- Pocket Pro：尺寸（和手机比宽）→ 重量 → 双电压 → 两种风嘴 → 电机/风速/吹干时间 → 负离子 → 恒温 → 静音 → 模式档位。先讲便携，再讲性能，再讲护发。
- AirStyle Suite：卷发 → 三合一总览 → 圆梳蓬松 → 吹风 → 细节四格 → 礼盒场景 → 包装清单 → 全家福白底。按配件逐个讲。

**版式**（和清洁类明显不同）：
- Pocket Pro **没有底部标题条**：标题在顶部居中，双色写法（关键数字或关键词用金棕色，其余黑色），下方一行灰色副标题。例如 `110,000 RPM Motor, Salon-Grade Power`、`Quiet Power. Peaceful Drying`、`Smart NTC Temperature Control`。
- AirStyle Suite 保留底部焦糖色标题条 + 副标题，副标题写对应配件名（`32mm Auto-Wrap Barrels`、`Round Volumizing Brush`），右下角放该配件的小图。
- 底色跟着产品颜色走：Pocket Pro 玫瑰金 → 香槟/奶油色底；AirStyle Suite 焦糖皮革 → 米色丝绸褶皱底。

**标题写法**：短句、感受导向：`No more wrist fatigue`、`As Wide As a Phone`、`Weighs Only 10.6 oz`、`Bouncy Waves & Defined Curls`、`Elegant Gifting`。

**数字可视化**：
- 重量：超大浅色数字 `300g` 放在产品背后，手掌托着产品。
- 吹干时间：三张人像小卡按发长排（Short 40sec / Medium 2min / Long 3min），配左侧白卡写 `110,000RPM`、`70m/s`。
- 护发效果：Before/After 圆形放大镜看发丝，下方一排百分比（`+51% Shine`、`+11% Smooth`、`-37% Frizzy`）。
- 恒温：折线图，自家一条平线 vs 泛称 “Dryer Without Temperature Control” 的波动线。
- 噪音：四格刻度（街道 70dB / 办公室 60dB / 自家 / 图书馆 40dB），自家那格高亮。
- 按键：引线标注（Short press / Long press / High-Speed / Low-Speed / Off）。

**场景和人物**：几乎每张都有模特，不同发质（金色波浪、黑色直发、卷发、短发）各配一种用法；人物是半身近景、白/米色上衣，和底色统一。用手机做尺寸参照；静音图里女生和狗坐在沙发前；有礼物场景（节日礼盒）。Pocket Pro 副图里放了 TIME Best Inventions 奖章。

**A+**：
- AirStyle Suite：开头横幅（产品 + 皮质收纳包放丝绸上 + 一句定位 `Effortless Everyday Styling`）→ 卖点总览拼格 → 每块一个功能：模特在一侧、文字在另一侧，米色底，金棕色数字（`60m/s`、`110,000 RPM`）→ 细节三格 → 按键引线图 → 套装清单（编号列表）→ 送礼 → 品牌产品线横幅。
- Pocket Pro：代言人横幅开头和结尾各一次，中间基本是副图的横版重排（双电压、收纳、风嘴、吹干时间、静音、负离子、恒温、档位、开箱）。

**主图**：两款都是产品 + 随货配件（风嘴、圆梳、收纳包）白底，没有文字，可参考。

## 三类对比（一句话）

- 清洁类：统一底部焦糖标题条，图里放数字卡 + 对比卡，偏“参数 + 证明”。机器人少人多宠物；洗地机人多、有步骤、有副标题。
- 个护：标题移到顶部（Pocket Pro）或保留底部条（AirStyle），底色随产品颜色，几乎每张有模特，偏“效果 + 感受”。

## 可以怎么借鉴（按需挑选）

- 可以给整组副图定一个固定的标题位置和底色条，让 7–8 张图看起来是一套；条的颜色可以从我方产品或包装的主色里取。
- 可以考虑“大数字 + 小标签”的写法：数字放大、换色，说明文字缩小放旁边，并在下方加一行测试条件脚注。
- 吸力、容量、续航这类参数，可以考虑贴在产品对应部位上（如水箱容量直接标在水箱旁），比单独列表直观。
- 对比图可以用“自家亮色 + 打勾 / Others 灰色”的左右卡，但只比泛称 Others，且数据要有我方实测依据；没有依据就不做对比图，改成单独展示自家数值。
- 个护或外观类产品可以考虑让副图底色跟产品颜色走，模特服装也用同色系。
- 尺寸、重量可以用常见物品做参照（如手机、手掌），参照物只出现在副图，不进主图。
- A+ 可以考虑“开头横幅 → 卖点总览拼格 → 每块一个卖点左右交替”的顺序；总览拼格适合卖点多的产品。
- 洗地机这类有操作流程的产品，可以考虑加一张带编号的步骤图，或在 A+ 放 FAQ 模块回答常见问题。
- 代言人、销量第一、奖项墙这类品牌背书，没有对应证据时不做。
