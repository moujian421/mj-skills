# 标签库：三轮折叠高尔夫推车（手推）

- 适用：三轮、可折叠的手推高尔夫球车（GC1/GC2 的竞品）。电动或四轮推车另建一份。
- 来源：2026-10 从飞书「高尔夫推车-Review 打标」迁移（32 个 ASIN 共 298 条，只打了 1–3 星）。迁移时做了这些清理：「做工不值其售价」拆成「做工粗糙」和「性价比低」；「客服不回复/无渠道」「拒绝退换/不补发」合并为「售后差」；「缺少伞架」「伞架设计与质量」合并为「伞架问题」；给「球包摩擦车轮」和「球包放不稳/不匹配」写了互斥规则（原表两者有重叠）。
- 正面标签是 2026-10-30 起草的初版，还没有用好评样本校准。第一次用时，按 SKILL.md 第 3 步抽好评样本核对一遍。
