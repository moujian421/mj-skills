# 西柚洞察（mj-xydc）

来源：西柚知识库 https://knowledge.xydc.com/docs/ 全部 25 个文档页、两份官方 PDF（全功能拆解思维导图、培训 PPT），以及「功能上新」「运营干货」两个标签下的 39 篇文章，FAQ 页的功能使用和数据指标问题（2026-10-28 抓取）。指标口径细节、展示位缩写、抓取邮编、更新频率见 `references/faq.md`；文章里的打法和案例见 `references/articles.md`。原文纯文本存在 `references/sources/`（docs / faq / blog-new / blog-ops / pdf），遇到这里没写的细节先 grep 原文，不要凭印象补。

西柚 = 西柚找词升级后的「西柚洞察」。网页功能和 `xydc-mcp` 工具不是一一对应；下面「功能 → 工具」表是 Claude 对照工具说明做的映射，调用前以工具自身的 Use when / Avoid when 为准。

## 1. 核心指标口径（解读数据前先对齐）

| 指标 | 口径 | 怎么用 |
|---|---|---|
| 流量 | 曝光权重分：按关键词周搜索量 × ASIN 所在位置的曝光价值 × 展示时长加权；只算搜索结果前 3 页（含各类推荐位），**不含当天**、不含详情页 | 后台广告展示量通常是它的 2–30 倍，不能直接对账 |
| 流量得分 / 7 天流量得分 | 流量 × 0.025；= 自然流量得分 + 广告流量得分；区间得分 = 每日得分相加 | 只做相对比较（自己 vs 竞品、本周 vs 上周）；**不是订单占比** |
| 自然 / 广告流量获得率 | ASIN 在该词前 3 页获得的自然（广告）流量 ÷ 该词总搜索次数；= 每次搜索被展示的平均概率，占多个位置时可 >100%。自然获得率 = 所在页权重系数 × 页内排名衰减系数 + 页面基础曝光率 | 比列表上显示的单个排名（如 P1-1）可靠；判断“这个词稳不稳”、能否收广告 |
| 关键词档位（按自然流量获得率） | 第一档 ≥40%；第二档 10–40%；第三档 3–10%；第四档 0–3%；无档位（也叫纯广告）= 没有自然流量。3/10/40 是西柚统计全站数据发现的断层点 | 两处用法要分清：**反查关键词**里是给“一个 ASIN 的各个词”分档（一档词增多 = 自然流量越来越稳）；**关键词分析**里是给“一个词下的各个 ASIN”分一至四档（找同档、相邻档竞品和升档黑马） |
| 流量占比 | 时间范围内 ASIN 在该词的展示量 ÷ 该 ASIN 所有词展示量之和 | 找主推词、流量来源词；单词占比 >60% 视为**流量集中型** |
| 流量份额 | 同一关键词下的流量分配，**分母看模块**：多 ASIN 对比 = 勾选的对比 ASIN 之和；父体分析 = 同父体各变体之和（变体流量份额）；广告分析 = 父体广告流量（变体份额、SP/SB/SBV 份额） | 看词是否被某 ASIN 垄断、找流量缺口、找主推变体 |
| ASIN 数量（多 ASIN 对比） | 对比的 ASIN 里有几个以该词为流量词 | 越多越相关；没开自动相关性时用它快速筛强/中相关词（例：下限设为对比数的一半） |
| 头部 / 腰部 / 长尾词 | 按 ABA 搜索频率排名：头部 Top 1 万；腰部 1 万–10 万；长尾 >10 万 | 判断 ASIN 吃的是大词还是长尾 |
| 竞争难度（反查关键词、以词找词的关键词列表） | 由搜索量、竞争度、广告竞争度综合计算 | ≥100 超难；80–100 难；60–80 中等；<60 简单。优先选“搜索量大 + 难度低” |
| 关键词广告位竞争难度（关键词分析页） | 同样由搜索量、竞争度、广告竞争度综合计算 | 官方**没给**档位阈值，不要套用上一行的 60/80/100 |
| 关键词自然位滚动率 | 由自然位数量、自然位 ASIN 数量等综合计算 | 越小 = 自然位固定、易守难攻；越大 = 变化频繁、易攻难守 |
| 搜索结果 ASIN 数量 | 分子 = 该位置近 30 天出现过的 ASIN 数；分母 = 最近一次抓取的位置数 | 例 自然 368/48：平均每个自然位 7.6 个 ASIN 在抢 |
| Top3 点击 / 购买份额 | ABA 报告中点击（转化）最多的 3 个 ASIN 份额之和 | 判断头部垄断程度、该词值不值得投 |
| 点击转化率 | **全周期**转化率（工具字段 `adjustedClickConversionRate`，小数）。ABA / 商机探测器只算搜索后 24h 内成交，非标品会严重低估（dresses 24h 仅 0.6%），西柚按 24h 订单占比校正 | 和卖家后台“商品推广搜索词报告”的 7 天转化率比，判断新品能否起飞；算 CPA/ACoS 用这个，别用 ABA 的 24h 口径 |
| CPC 建议竞价 | 西柚自研单点值：CPC 上限 < 净价 × 毛利率 × 全周期 CVR（净价 = 标价 ×（1−优惠券）− Deal），再按竞争难度定位 | **不是**实际出价或实际花费；后台报表 CPC ≈ 自己出价，不能拿来验证它。进类目前估真实 CPC 用 `mj-category-cpc`（高转化、低难度类目会被明显低估） |
| 广告位 P1-1 | 搜索结果第 1 页第 1 个广告位 | 放映机、金主榜通用 |
| 广告金主榜百分比 / 广告份额 | ASIN 近 7 天出现在该广告位的时长占比 | 越高垄断越强；找垄断低的高性价比广告位 |
| 关键词数量 | 所选时间段 ASIN 出现在搜索结果前 3 页的关键词数 | 越多流量来源越广 |
| 各位置流量占比 | 展示位流量 ÷ ASIN 总流量（广告洞察里是 ÷ 广告总流量） | 看流量主要来自哪个位置。**算自然流量的位置**：自然排名、AC、ER、CPF 中的自然位、OOR；**算广告流量的位置**：SP、SB、SBV、HR、TRB、CPF 中的广告位、SOR（缩写解释见 `references/faq.md`） |
| 订单量 | 抓的是亚马逊搜索结果页外显的“past month bought” | 月销 <50 不外显，西柚就没有数据 |

## 2. 亚马逊流量分配三阶段 + 异动关键词

西柚的观察模型（培训 PPT 原话要点：需要流量的 ASIN 远多于有流量的位置，例如 1 万个 ASIN 抢 48 个位置，所以算法会考核点击率和转化率）：

| 阶段 | 表现 | 系统在考核 |
|---|---|---|
| 稀疏期（小流量测试） | 一天只有少数几个小时有前 3 页排名 | 有效点击、有效出单 |
| 震荡期（放量测试） | 一天大部分时间有前 3 页排名，但排名上下波动大 | 不同位置的点击率、转化率；表现差会回落到稀疏期 |
| 稳定期 | 排名稳定，持续拿自然流量 | — |

异动关键词（反查关键词页，原名“今日关注”）：
- **口径变化**：旧文档写“升档 = 稀疏→震荡→稳定”；2026-01 新版改为按关键词的**自然流量获得率档位**（3% / 10% / 40%）变化判定，只统计有小时级排名的词。「昨日异动」= 今天 vs 昨天的档位变化；「近 7 天异动」= 7 天内最后一次档位变动。两种说法方向一致，解读按新版。
- **新增**：昨天前 3 页没有自然排名，今天有 → 先判断相关性，相关就加广告稳住排名。
- **流失**：昨天有，今天没了 → 是核心流量词就重点处理。
- **流量升档** → 机会窗口。培训 PPT 的建议：已有自然排名的词加广告巩固；行业大词可配合活动促销冲。
- **流量降档** → 预警，排查是哪些词排名在波动。

## 4. 场景打法（官方 7 大场景 + 文章补充）

### A. 搭建关键词库
1. 收集：BSR 选 10 个强同质竞品（价格、评分评论、功能、BSR 相近）→ 多 ASIN 对比反查，时间拉到近 1 年；再用以词找词从 3–5 个核心词根拓长尾，同样选 1 年。
2. 筛选：用 ≥10 个强竞品 ASIN 自动标相关性。强/高/中 → 词库；低/极低 → 否词库。用「7 天自然流量获得率 Top50」的主图人工校正。
3. 分类：数据维度（周搜索量大/中/小、竞争难度、点击转化率交叉）+ 属性维度（人群、场景、产品功能/材质/颜色、价值：产品价值 vs 情绪价值）。用单词词频找属性词根。
4. 定期按竞品和类目变化更新。
- 季节品：时间范围选去年需求高峰期和攀升期，找当时处于攀升期的词，提前布局。

### B. 拆解对标竞品打法
1. 关键词分析的 ASIN 列表里按价格、评分、评论数找强同质竞品 → 多 ASIN 对比：关键词数量、流量份额、流量占比、排名对比。
2. 父体分析：先确认分析对象是父体下流量最大的变体。
3. 流量洞察：流量来源、头腰尾词贡献、各展示位对应的词。
4. 广告洞察：广告流量构成、各广告位 Top10 词。
5. 反查的趋势视图：看竞品在每个词下广告持续时长、自然排名是否随之上涨；切展示位看推广节奏。
6. 补充：价格趋势（定价策略）、coupon / deal（促销节奏）、BSR 波动（运营动作对销量的影响）、订单量分析（变体销量波动）。

### C. 透视竞品广告策略和预算
广告分析输入竞品 ASIN → 变体份额定主推变体 → 广告类型看 SP/SB/SBV 占比 → 点各类型份额看哪些广告活动贡献流量 → 展示时间看每天展示时长（时长突然变长 ≈ 加了预算或竞价）→ 广告关键词列表看核心词和流量占比 → 广告活动的搜索词数量和列表用来判断匹配方式。

### D. 提升新品推广效率
- 用三阶段判断每个词所处阶段，盯异动关键词抓窗口（见第 2 节）。
- **一步判断新品能否起飞**：后台“商品推广搜索词报告”的 7 天转化率 vs 西柚该词点击转化率。高于 → 已起飞，可加大推广；低于 → 官方只说“有优化调整空间”，加大推广要慎重，具体优化方向由 Claude 结合 Listing、价格、评论数据判断。

### E. 实时监控广告投放效果
- 小时级排名：美国站最新一周 ABA 前 10 万词、英德前 5 万词每小时抓 1 次（网页上带 🚀 标）。
- 广告正向干预：广告排名在、自然排名稳步上升；无效干预：持续投放但自然排名不动。
- 广告放映机：有优势就对着竞品的广告位正面抢；没优势就错峰投放。时间是站点当地时间（美国站 = 美西）。
- 自然放映机：排名越靠前越稳定；参考自然位靠前 ASIN 的主图。

### F. 找高性价比流量缺口
- 多 ASIN 对比：竞品有自然排名或在投广告、我们没排名的词 = 缺口。
- 广告金主榜：找垄断百分比低的广告位。
- 关键词分析：搜索结果 ASIN 数量、自然位滚动率、广告位竞争难度判断难度。
- 反查的自然流量获得率判断增量空间；“机会词”标签筛有流量且难度低的词。
- **广告增减时机**：看词下各 ASIN 的自然流量获得率天花板；自己的获得率对后面竞品有稳定优势时，可阶段性收缩广告追利润。

### G. 分析 ASIN 流量结构 / 多变体
- 单 ASIN：流量趋势 → 流量占比 & 展示位置 → 流量诊断仪（异常日）。
- 流量诊断三步：找异常流量柱 → 看哪个展示位掉了 → 点进去找带动下降的 Top20 词；原因按 ①该词流量占比 ②该词排名变化 ③该词搜索量变化 排查。
- 多变体：父体分析看主推款；**属性订单量份额 > 流量份额 = 高转化潜力款**；父体流量趋势配价格曲线看定价策略；变体关键词列表看各变体在核心词的排名。

### H. 官方解读规则速查（详见 `references/articles.md` 第 3 节）
- **关键词数量是领先指标**，流量、销量滞后：广告词和自然词同步涨 = 广告在孵化自然词；广告词暴涨但一档自然词减少 = 核心排名在丢；广告词暴涨且多为 SB/SBV 长尾、无自然排名 = 竞品在大规模测词；自然流量大跌、SP/SOR 大涨补位 = 疑断货/差评/被攻击。
- **档位剪刀差**：一二档涨、无档位跌 = 运营有效；一档跌、二三档涨 = 核心词在退；彩色全跌、无档位猛涨 = Listing 或类目出问题。Deal 后一档词数上升 = 秒杀拉动了权重。
- **父体**：流量份额变化是卖家动作（因），订单份额变化是市场反馈（果）；均价持续下滑且 Deal 拉动越来越弱 = 进入衰退期。
- **Deal**：降价后自然流量和 SP 排名一起涨；原本无效的广告降价后起量 = 价格在拖累。
- 卖家经验类做法（广告订单占比四阶段、毛利/CPA 阈值、单活动测试规则等）放在 `references/articles.md` 第 4 节，标【经验】，引用时说明是经验值。

## 5. 关键词相关性（以词找词、多 ASIN 对比的自动标注）

- 原理：一批 ASIN 在该词下的总体自然表现越好（官方另一处说法是“平均自然流量获得率”越高）、获得自然流量的 ASIN 越多，相关性越高。
- 不准的情况：①输入的 ASIN 和词根搜索意图不符（如方形狗窝去测 donut dog bed）；②ASIN 相关但自然表现差；③ASIN 太少（官方建议 ≥10 个）；④ABA 排名很靠后（如 200 万名+）的词强 ASIN 也覆盖不到，会偏低；⑤近期没进 ABA 报告的词没有相关性。
- MCP：`find_related_keywords` 的 `reference_asins` 传 10–20 个强竞品子 ASIN，返回 0–100 分和 strong/high/medium/low/extremelyLow 分层。

## 6. 数据限制

- 更新频率：小时级排名和放映机每小时；流量类每天；周搜索量、ABA 排名、Top3 份额、流量周报每周（周搜索量比 ABA 晚一周）。
- 抓电脑端、固定邮编（美国 90001），和前台看到的排名不一致属正常；排名趋势断点 = 当时不在前 3 页。
- 以词找词的“匹配方式”只是和词根的匹配关系，不是广告匹配建议。
- 广告活动后的 4 位编码 = 后台 SP 活动 ID 后 4 位，可和自家后台对号。
- 排名和流量只看搜索结果前 3 页；小时级只有 US/UK/DE 且限 ABA 前 10 万（美）/ 5 万（英德）词；放映机工具同样只支持 US/UK/DE。
- 流量得分是估算值；CPC 是建议竞价；放映机只代表当天观测到的广告位，不代表活动完整周期或是否停投。
- 订单量月销 <50 时无数据。
- 头腰尾词按 ABA 排名划分，不是按西柚搜索量。

## 7. 调用规范

- 每次调用都填 `user_task`（用户原话，同一任务保持一致）和 `intent_summary`（本次调用目的）。
- 西柚按次扣 Credits。已知（来自其他 mj skill 实测）：类目洞察资源约 500 Credits，同任务只生成一次；趋势类接口约每 6 个月 5 Credits；`get_category_keywords` 每 20 词 1 Credit；价格/排名趋势单次 4–7 Credits；`get_asin_info_trends` 约 1 Credit。大批量或高价调用先把清单和预估 Credits 给用户确认；`get_account_credit_quota` 查余额。
- 多账号（2026-11-04 用户规则，全局 CLAUDE.md「西柚 MCP 额度规则」）：先用 `xydc-mcp`（1 号）和 `xydc-mcp-2`（2 号，批量默认），一个不够切另一个；两个都不够才用 `xydc-mcp-3`，用前提醒用户并查 `get_account_credit_quota`，3 号剩余 ≤ 5000 停用。单个任务预估 > 500 Credits 先请示用户。resourceId 只在生成它的账号内有效，换账号要重新生成（约 500 Credits，先请示）。

- 比例字段是小数（0.2 = 20%）；分页续页时其他参数不变只递增 page。
- 西柚缺某个能力时，可用 `report_missing_xiyou_capability` 反馈。
