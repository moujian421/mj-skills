## 2. 指标算法补充【官方】

- **自然流量获得率** = ASIN 所在搜索结果页权重系数 × 自然排名衰减系数 + 页面基础曝光率。页越靠前曝光越高；同一页内排名越靠前，衰减越慢。用它代替单次排名，因为单次排名有瞬时性、不可累加、难横向比（april-feature-release-2、bu-zai-mang-cai-yan-gao-xiao-guo）。
- **档位断点 3% / 10% / 40%**：西柚统计美国站某天全部 ASIN 在全部词下的自然流量获得率，在这三处出现明显断层，所以这样分档（keyword-traffic-tiers）。
- **异动关键词**只统计有小时级排名的词；“近 7 天异动”显示 7 天内最后一次档位变动（asin-research-v2）。
- **全周期点击转化率**：亚马逊品牌分析 / 商机探测器的转化率只算搜索后 24 小时内成交的订单（CVR_24h）。标品（如电池）24h 内下单占比 >95%，非标品（如裙子）<25%，dresses 的 CVR_24h 只有 0.6%。西柚按 24h 订单占比换算成全周期转化率。用 24h 口径算非标类目的 CPA/ACoS 会严重高估（cvr、cvr2）。
- **CPC 建议竞价**：约束 CPA = CPC ÷ CVR < 净价 × 毛利率 → **CPC 上限 < 净价 × 毛利率 × CVR**。净价 = 标价 ×（1 − 优惠券）− Deal 折扣；CVR 用全周期转化率。例：净价 $30、毛利 30%、CVR 5% → CPC 上限 $0.45。再结合竞争难度（广告位容量、参与 ASIN 规模）定位建议值。后台报表的 CPC ≈ 你自己的出价，不能用来验证建议值；亚马逊接口的建议竞价（同一个词 7 类目 × 3 匹配 × 2 竞价类型 = 42 个值，最高 $10、最低 $0.35，词组 $7.07 vs 精准 $1.07 倒挂）口径混乱，参考价值有限。选词顺序：先相关性，相关性相当选建议竞价更低的，再选竞争难度更低的（cpc）。
- **调整 Bid 后 2–3 小时**就能在小时级排名上看到效果（bu-zai-mang-cai-yan-gao-xiao-guo）。
- **广告分析的数据来源**：邮编 90001 无痕搜索抓前台广告位的五要素：ASIN、关键词、广告活动、adid、广告类型。ABA 前 100 万词占站内约 99% 流量和单量，前 10 万词占 90% 以上；前 10 万词每小时抓、10 万–100 万每天抓。广告组里有几个 ASIN 就有几个 adid（ad-analisis-ul）。
- **从 adid 词库推断匹配方式**（有误差）：大量低相关、少见词 → 自动；有相关但词序不连续 → 广泛；展开词最少 → 精准。广告关键词流量占比可粗略当预算占比看（前提是 CPC、CTR 差异不大）（ad-analisis-ul）。

## 3. 解读规则【官方】

**关键词数量是领先指标，流量和销量是滞后结果**（asin_search_terms_count、asin-research-v2）
- 广告词数涨，自然词数也同步涨 → 广告在有效孵化自然词。
- 广告词数暴涨、第一档自然词减少 → 核心自然排名在流失。
- 广告词数暴涨且多为 SB/SBV 长尾、几乎没有自然排名 → 竞品在大规模测词（案例：圣诞前）。
- 某展示位的词数陡增 → 预示该类广告的新攻势。
- 头部词数增 = 巩固大词；长尾词数增 = 低成本广撒网测试。
- 自然流量大降、SP/SOR 广告流量大涨补缺口 → 疑似断货、差评或被攻击后的防守。

**各档位关键词流量得分**（keyword-traffic-tiers）
- 柱子高且蓝绿（一二档）多 = 健康，利润空间好；柱子高但灰红（无档位、四档）多 = “虚胖”，靠广告撑。
- 蓝绿涨、灰红跌 → 运营有效；蓝跌、绿橙涨 → 核心词排名在退；彩色全跌、灰猛涨 → 大量词掉排名，疑 Listing 出问题、换类目或被算法惩罚。
- Deal 后几天第一档词数明显上升 → 秒杀拉动了自然权重；只涨销量不涨一档词 → 复盘 Deal 策略。

**父体 / 变体**（_variations_insight、parent-trend-release）
- 流量份额变化是卖家主动动作的“因”，订单份额变化是市场反馈的“果”。
- 某属性订单份额 > 流量份额（例：Red 用 6% 流量拿 13% 订单）→ 高转化潜力款，可单独建高竞价活动。
- 竞品主推款在两色之间季节性切换（春夏白、秋冬黑）→ 提前 1–2 个月备对应颜色的广告和库存。
- 平均价格走势对应生命周期：新品期震荡、成长期中幅波动、成熟期稳定加阶段促销、衰退期频繁降价清货。均价持续下滑且促销对流量拉动越来越弱 → 进入衰退期。

**Deal 与流量**（deal_and_traffic_relationship、april-feature-release-3）
- 降价促销 → 点击率转化率上升 → 自然流量和 SP 排名一起上涨；促销结束后广告仍能稳在前 3 页说明促销带稳了广告位。
- 原本无效的广告配合降价后广告流量起来 → 是价格在拖累广告。
- 多个升档 ASIN 都在做 Deal → 可以考虑跟进 Deal 或加广告防守。

**竞品旺季复盘**（daily_historical_data）：用日维度看节前一周 vs 节日当周。案例：节前一周以品类词自然流量为主，节日当周换成礼物词，广告流量占比冲到 50% 以上（大量 SOR）。

**西柚数据研究**（natural-rank-regain）：2024-10-29 美国站大面积自然流量骤降（平均自然流量得分降 95%），11-17 起逐步恢复；高流量 ASIN（>200 分）平均恢复到 106%，50–200 分的只恢复 65%。说明全站性异常时，先看是否大盘问题再归因自己。

## 4. 卖家实操经验【经验】

只作参考，阈值因类目而异。

**选词 / 词库**
- 词库规模：核心流量词 ≤10 个，中流量属性词约 50 个，长尾约 300 个；做 5000 词只用 500 就没意义（build-keyword-list）。
- 毛利 ÷ CPA ≥50% 的词可长期投；<30% 先把钱投别的词（build-keyword-list）。
- 长尾词投放用精准匹配；不相关词频用排除短语或后台否定（build-keyword-list）。
- 季节品：旺季前 2–3 个月是冲自然排名的黄金窗口，非旺季冲首页所需单量和广告费可能只有高峰期的几百分之一（spring dress 搜索量差近 200 倍）。多 ASIN 对比时间选去年旺季，ASIN 数量下限设为勾选数的一半 → 超过一半竞品都有的词基本是精准词（low-cost-organic-ranking-boost）。
- 只投“现在就有搜索量”的词，季节性长尾在旺季前没流量跑不出数据（new-product-ads）。和上一条不矛盾：旺季前 2–3 个月提前卡位的是**搜索量已开始爬升的核心词**；还没有搜索量的季节性长尾等它有量再投。
- 老品选自然排名 15–30 名的词投，把它们养进前 15；新品选周搜索量 >1000 的词分析（how-to-use1）。
- 长尾 AB、ABC 表现好会反哺主词 A 的排名（keyword_extension）。
- 非标品需求分散，只看搜索前 10 名判断相关性不科学，用 Top50 + 批量 ASIN（keyword_extension）。

**广告结构与节奏**
- 10–20 个搜索量相近的词一组建精准活动，竞价从 $1 起测、无曝光再加，每个词跑到约 15 个点击再横向比（new-product-ads、bai-mao...）。
- 单活动精准测试：保证 10 次以上点击；投放后 4 天内只增减预算不改别的（how-to-use2）。
- 中大流量词单词单活动（看出单和排名），其他词多词单活动（看 ACoS）（how-to-use1）。
- 自动广告“瀑布流”：同一活动设高中低三档竞价覆盖不同时段；高竞价组否品牌词和大词，大词单开手动（new_product_launch_strategy）。
- 大词决定上限，长尾决定下限（new_product_launch_strategy）。
- 多位作者认为：影响关键词自然排名的只有该词下的点击和出单；SB/SBV 对自然排名几乎没有加持；自动广告出单带不动具体词的排名；站外放量冲销量但不加权重（how-to-use2、how-to-replay、new-product-ads、bai-mao...）。
- 预算收缩要“软着陆”，逐步降，避免流量和销量腰斩（new_product_launch_strategy2）。
- 竞品广告中午就烧完预算 → 下午错峰投（competitor-analysis）。
- 高客单产品在 TOS 前几位展示少，投第二页或首页后段性价比更高（how-to-use2）。

**判断链接状态**
- 广告订单占比四阶段：100% = 没有任何自然排名；80% = 有自然排名但流量小；50% = 词在首页尾部或二三页头部；30% = 词在首页头部；≤20% = 大流量词基本在首页前 10（how-to-replay）。
- 广告流量占比 ≤30% 且单量稳定 → 第一阶段大概率成功、盈利（how-to-use1）。
- 新品转化率 5% 判死刑、>10% 可推（某服装案例，bai-mao...）。
- 自然排名前 16 名即首页，需重点关注、加广告补曝光（bai-mao...）。
- 广告订单占比上扬、单量却看不出问题 → 链接可能已经出问题（how-to-replay）。
- 旺季前 1–2 个月把自然排名稳住；做完 Deal 后自然排名不大幅波动 = 已稳定；稳排名 = 稳出单 = 敢备货（new_product_launch_strategy3）。
- 补货量 = 旺季目标日销 × 销售天数 − 当前总库存（在售 + 在途 + 待发）（new_product_launch_strategy3）。

**差异化案例**（casestudy）：3C 标品（开放式耳机）关键词列表前面出现风格、人群词 → 亚马逊在给链接打人群标签；据此把标题里的饰品/珠宝词前移、主图改为突出配饰、广告转投饰品和女性词，避开参数价格战。

**其他判断**
- ABA 排名受全站大盘影响，排名下降不等于搜索量或订单下降（how-to-use1）。
- Top3 点击份额下降 → 头部垄断在松动，可能是进入时机（how-to-use1）。
- 流量得分很低、订单量不高的竞品不值得深入分析（campaign-name）。
- 换店铺上架 → 自然流量归零，需要重推（new-product-ads）。
