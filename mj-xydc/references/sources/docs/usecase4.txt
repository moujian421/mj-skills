# 
实时监控广告投放效果
### 1、每小时更新关键词排名--判断广告投放效率
西柚洞察小时级排名目前应用在美英德三个站点中，针对最新一周ABA报告美国站前10万，英国站和德国站前5万的关键词1个小时抓取1次关键词排名。
在关键词后面带有“🚀”火箭标志的，都是我们拥有小时级排名趋势的关键词，也就是我们会1个小时抓取1次关键词搜索结果页中的排名数据，并进行更新。
点击“自然排名/广告排名”数字，即可看到ASIN在关键词下的排名变化趋势情况。
图源：反查关键词–-ASIN列表
我们能够通过小时级的广告排名变化情况，及时了解广告投放所出现的位置，位置持续的时间，来评价广告投放的效率或者效果，根据所投放的广告是否有带来自然排名的提升，从而增加自然流量。
以下是广告投放的两种情况：
1.1 广告正向干预--广告投放带动自然位上升
好的广告投放，能够稳步带动自然排名的上升，增加产品在关键词下的自然流量。
图源：点击“自然排名”/“广告排名”数字即可查看
1.2  广告无效干预--广告投放没带来自然排名上升
无效广告投放，没有能够稳步带动自然排名的上升，增加产品在关键词下的自然流量。
图源：点击“自然排名”/“广告排名”数字即可查看
## 2、广告放映机--快速找到关键词市场下广告坑位占据情况
在广告放映机中，我们能够清楚地看到每个小时，每个广告位置上出现的ASIN是哪些。
TIPS：
1、有优势：如果对比竞争对手，我们的产品有足够的优势，可直接对着竞争对手所投的广告位置进行投放，抢夺广告位。
2、无优势：如果我们没有足够的优势的话，可以与竞争对手错峰投放，避开竞争的时间。

图源：关键词分析-广告放映机功能
## 3、自然放映机--分析关键词自然坑位情况
在自然放映机中， 我们能够看到每小时自然位置上的ASIN都是哪些。我们能够知道ASIN自然排名越靠前，自然排名越稳定。
同时我们还能够观察到，自然排名靠前的ASIN图片有什么值得参考的地方。因为自然排名靠前的ASIN点击和转化都相对来说会更高一些。
图源：关键词分析--自然放映机功能
