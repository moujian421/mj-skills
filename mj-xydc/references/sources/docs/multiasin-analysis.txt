# 
多ASIN对比
[图:多ASIN对比]
## 使用场景
### 1、快速进行竞品信息对比
通过“7天流量得分（自然-广告）”，能够判断快速目前哪个ASIN的展示量最大，获得的流量最多；以及当前各ASIN自然-广告比例情况，哪些以自然流量为主，哪些以广告流量为主。
通过“关键词数量（自然-广告）”，能够知道ASIN的关键词流量来源情况，数量越多，流量来源越广；
通过“近30天订单量”能够快速查看各ASIN订单量变化情况，和流量进行对比。
⚠️注意：所有的指标都可以点击进行升降序排序，可根据自己想看的指标进行排序对比。
[图:图源：多ASIN对比]
图源：多ASIN对比
### 2、自动筛选相关性
在“多ASIN对比”中，可输入20个ASIN同时进行对比。
根据对比ASIN在词下的平均自然流量获得率（即自然表现），自动判断相关性。
[图:图源：多ASIN对比]
图源：多ASIN对比-相关性判断
### 3、快速分析关键词覆盖差异情况以及流量结构
通过“流量份额”，能够快速知道对比ASIN在同一关键词下的竞争情况，快速找到和竞争对手之间的关键词流量缺口；
通过“流量占比”，我们能够快速了解各个ASIN的主要流量来源词是哪些，以及关键词的侧重点在哪里，分析ASIN流量结构差异。
[图:图源：多ASIN对比--流量份额&流量占比]
图源：多ASIN对比--流量份额&流量占比

点击“自然排名”或“广告排名”数字，能够快速查看各对比ASIN在同一关键词的排名对比情况，找到排名差距情况
