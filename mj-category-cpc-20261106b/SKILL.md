## 核心结论（用户确认过的口径）

- **西柚建议 CPC 不是市场成交价**。它按“净价 × 毛利率 × CVR”再按竞争难度往下压；转化率高、难度显示“简单”的类目会被低估（MH：真实 ＄5.0 vs 西柚 ＄2.7）。
- **西柚转化率 ≈ BSR 前 10 的平均转化率，当作头部产品的目标转化率**（用户判断，MH 类目用户估前 10 平均约 21%，西柚 20.4%；验证：GF1 1.1–1.3 倍、AB10 1.0–1.7 倍、MH 类目卖得最好的竞品约 0.9 倍，头部 ≈ 0.9–1.3 × C）。它是按点击加权的整词平均；ABA 里点击前 3 的 ASIN 往往低于它（吃了比价点击），但真正的头部产品能做到或超过它。
- **CVR 只看广告 CVR**（用户要求），不要用会话转化率。
- **基准不动**（用户要求 2026-11-06）：上面和“公式”表里的 0.22V / 0.40V、西柚原始 C 是基准，脚本主行照旧输出。下面三条是 PM1 得出的**微调参考**，脚本在主行下面单独打一行“↳ 微调参考”，不覆盖基准；结论里两个都列，说明差在哪。之后有新数据就继续校准微调，攒够点再决定要不要动基准。
- **微调 1：周搜 <5000 的小词，西柚 C 可能严重失真**：PM1 的折叠长尾词西柚 C 只有 3.3–4.7%，PM1 在这些词上的实际广告 CVR 是 9–20%；同意图大词 yoga mat（周搜 13.8 万）C 10.7%，和 PM1 在该词的 11.3% 对得上。PM1 是清仓价（原价 ＄59.99 打七折），但按市场看它在同形态中位价附近（＄36–40），价格解释不了 3.6 倍；另有独立证据：ABA 里 PM1 子体在 foldable yoga mat thick 点击 8.1%、转化 0，同期广告 67 次点击 14 单，小词 ABA 转化数据本身就漏单。规则：小词 C 不到大词 C 的一半时改用大词 C（周搜 ≥1 万的词按搜索量加权；脚本自动做，也可用 `--c-ref` 指定）。小词 C 偏高（MH 小词 22–40%）时不动。**只借同价位的大词**（2026-11-06 核桃砧板反例）：大词必须也拉了 `asin_analysis`，且前 20 中位价是小词中位价的 0.7–1.43 倍，脚本才拿它的 C；没有可比价位的大词就不改 C，标“低 C 多半是价位高的真实转化”。核桃砧板 walnut cutting board C 6.7%，大词 C 19.5% 来自 ＄10–30 竹砧板（wood cutting board 中位价 ＄30，walnut 词 ＄62），换 C 后估 ＄2.6，实际 CPC ＄0.96、CVR 4.7%。
- **微调 2：低客单（P < ＄50）时西柚 CPC 当下限**：不是混合需求词、词也对口时，靠后 CPC 取 max(0.22V, 西柚 CPC)，抢顶部取 max(0.40V, 2×西柚 CPC)。低客单类目（PM1 P ＄32–43）纯 V 模型会低估一半以上，西柚 CPC 反而接近实际（yoga mat 西柚 ＄1.63 vs 实际 ＄1.60；folding yoga mat 2×西柚 ＄2.20 vs 实际 ＄1.99–2.18）。P ≥ ＄50 的旧校准点（GF1/GF2/MH/PB1/WD1/AB10）不用这条，结果和原来一样。
- **微调 3：传了 `--same` 时，同形态内再剔 >2× 中位价的大件算 P**（PM1：Stakt ＄94–128 把 P 从 ＄37 拉到 ＄48–63）。
- **公式和西柚冲突时，不凭直觉往西柚靠**（2026-11-06 核桃砧板教训）：P ≥ ＄50 且西柚 CPC > 0.3V 时，点估计用基准 0.22V，西柚 CPC 只当“放开抢位”的情境另列；不能因为“竞品多、新品重投、旺季”就把点估计往西柚调。核桃砧板西柚 ＄1.91（0.41V），Claude 当时判断偏西柚 ＄1.9，实际 ＄0.96（0.21V），基准 ＄1.02 才对。历史上 P ≥ ＄50、西柚高于公式的点是两两分歧：pilates board（0.27V → 实际 0.18V，封顶）、核桃砧板（0.41V → 0.21V）偏公式；gym mats（0.29V → 0.29V）、foam floor tiles（P ＄61，0.39V → 0.48V）偏西柚。所以结论里给“基准 ~ 西柚”两个情境，基准是点估计。
- **价位错配只预警、不改数**（Argon 建议，等真实数据）：词下前 20 中位价不到同形态 P 的 70% 时，词 C 被低价带抬高，V 和基准 CPC 可能虚高（office chair、desk chair、wood cutting board）；我方售价 ≥ 词下中位价 1.5 倍时，我方 CVR 会明显低于 C。这两种词在结论里只当参考，不当主判断；CVR 改用价位相当的精准词的 C 估。攒够 3 个有真实数据的点再定替换公式。
- **产品位置按“稳定期广告 CVR + 当时主词自然排名”记录**（用户要求 2026-11-06）：校准时记录产品广告 CVR 稳定那几周的 CVR ÷ C，以及同期在各主词的自然排名（西柚 `get_asin_keyword_rank_trends`），见回测下面的“CVR 与自然排名”表。预估时先说清我方预计能排到哪，再查表取 CVR ÷ C。
- **CPC 取决于要拿多少搜索顶部展示份额（TOS）**，统一用 V 算：靠后位置（TOS <3%）≈ 0.22V（实测 0.17–0.24）；抢顶部（TOS 10–30%）≈ 0.40V（实测 0.36–0.45）；TOS 3–10% 取 0.25–0.35V。西柚定价正常的类目（西柚 CPC ≈ 0.22V，如 GF2）里，靠后约等于西柚建议价、抢顶部约 2 倍；西柚 CPC < 0.2V 时一律按 0.22V。
- **混合需求词要先剔掉异形态竞品**：主词下如果是饮水机、水槽下即热、保温壶这类不同形态的商品在投广告（WD1），P 和西柚 CPC 都会失真。只用同形态竞品算 P；同形态占广告流量很低时，靠后位置会比公式更便宜（WD1 hot water dispenser 实际 ＄0.81，公式 ＄1.46）。
- **动态竞价“提高和降低”在固定竞价市场价上再推高约 1.5 倍**（MH：同词固定竞价 ＄3.2–3.9 → 动态 ＄5.0）。“只降低”或出价太低时，实际 CPC 会被出价封顶（PB1），那不是市场价。

## 流程

0. **先确认入参**：计划售价、预计竞价策略（固定/只降低/提高和降低）、目标位置（靠后/抢顶部）。用户没说就按“固定竞价、靠后位置”算，并在结论里写明。
1. **定主词 3–5 个**：用户给，或从类目头部 ASIN 反查流量最大的词。**只看核心、流量较大的词**（用户要求 2026-11-06），例如 PM1 只看 yoga mat、pilates mat，再加 folding/foldable 里流量最大的一两个；周搜几百以下的长尾不进主词，CVR 也不看它们的。剔掉明显不对口的词。
2. **拉数**（每词约 1 Credit；超过 3 次调用按全局规则交 `batch-offload` 的 `cb_pull.sh`/`oc_pull.sh`；DeepSeek 免费额度用完、agy 又没有 `xydc-mcp-2` 权限规则时（2026-11-06 两个都不通），6 次以内 Claude 自己调，`asin_analysis` 每次约 25KB）。**主词里要带 1–2 个同意图的大词**（周搜 ≥1 万），给小词的 C 兜底；**大词也要拉 `asin_analysis`**，脚本靠它判断大词和小词是不是同一价位，没拉就不借大词 C：
   - `xydc-mcp get_keyword_info`：`keywords` 一次传完（≤100），拿 `clickConversionRate`、`costPerClick`、`competitiveDifficulty`、`abaReport.topAsins`。
   - `xydc-mcp get_keyword_asin_analysis`：每个主词一次，`page_size: 20`。
   - 可选 `sellersprite-mcp keyword_research` 看 PPC 竞价区间做旁证（卖家精灵每分钟限流，批量时会报 `ERROR_MAXIMUM_ACCESS_PER_MINUTE`，失败的单独补调）。
2b. **标同形态竞品**：Claude 读每个主词前 20 ASIN 的标题，挑出和我方形态、用途相同的 ASIN（不按价格判断），传给脚本 `--same`。所有词都是同形态时可以不传。
3. **跑脚本**：
   ```bash
   python3 -I ~/.claude/skills/mj-category-cpc-20261106b/scripts/estimate_cpc.py \
     --info <get_keyword_info 返回>.json \
     --asin "主词1=<asin_analysis 返回1>.json" --asin "主词2=<返回2>.json" \
     --price <我方计划售价> [--cvr <预计广告CVR>] [--same ASIN1,ASIN2,...] [--c-ref <大词C>] --out result.json
   ```
   主行和 `cpc_mid`/`cpc_head` 是基准；触发微调时多一行“↳ 微调参考”，JSON 里在 `adj` 字段（改了哪几条、C、P、V、CPC、ACoS）。
4. **处理预警**：出现“词可能不对口”的词，从结论里剔除，必要时回第 1 步换词；高价大件污染时脚本已自动剔除 >2× 中位价的 ASIN 重算 P（输出里保留原值）。
5. **解读**（下面的公式和阈值）。分两段给 ACoS：**上架前期**按 0.3C；**稳定后**先定我方预计在主词的自然排名，再查“CVR 与自然排名”表取 CVR ÷ C（表里没有可比的点时，头部 C / 中部 0.6C）。交 Argon 挑刺（全局规则），再给用户结论。

## 公式

| 量 | 算法 |
|---|---|
| P | 词下前 20 ASIN **按广告流量加权**的价格（谁在出价就用谁的价格）；有异形态时只用同形态 ASIN |
| C | 西柚点击转化率（微调：周搜 <5000 且不到大词 C 一半时参考大词 C） |
| **V（单次点击价值）** | P × C |
| 靠后位置 CPC（固定竞价，TOS <3%） | **0.22 × V**（区间 0.17–0.27）（微调：P < ＄50 时参考 max(0.22V, 西柚 CPC)，混合需求/不对口/大件污染时不用） |
| 中间（TOS 3–10%） | 0.25–0.35 × V |
| 抢顶部 CPC（固定竞价 + 顶部溢价 30–50%，TOS 10–30%） | **0.40 × V**（微调：P < ＄50 时参考 max(0.40V, 2 × 西柚 CPC)） |
| 开“提高和降低” | × 1.5 |
| 我方预计广告 CVR | 稳定后：按“CVR 与自然排名”表；没有可比点时头部 ≈ C，中部 ≈ 0.6 × C；上架前期/评论少/评分低 ≈ 0.3 × C。用户给了就用用户的，但同时列出 0.3C 的前期结果（PB1 用户按 4.5% 算，实际最好两周 1.9%） |
| **预估 ACoS** | 预估 CPC ÷ (我方售价 × 我方预计 CVR) |

## 局限（结论里要写）

- 样本 7 个产品；靠后档 0.22 有 GF2、WD1、AB10 三个成熟老品支撑，新品在靠后位置是否同样便宜还没验证；抢顶部系数 0.4 只有 GF1 一个干净的点（MH 是动态竞价）。“低客单用西柚 CPC 当下限”只有 PM1 一个类目支撑，是瑜伽垫特例还是低客单普遍规律还要再补点；PM1 的实际 CPC 全部被出价封顶，真实市场价可能更高。WD1 是混合需求词特例，不当通用校准点。新类目跑完、有真实数据后，把实际 CPC/V 补进校准表，更新系数和回测表。
- 复购型、品牌防守型类目，竞品按长期价值出价，系数会偏高。
- 大促期间 CPC 整体上浮；拉数避开大促周。
- 西柚数据抓的是最近一周；季节品要看旺季前后再拉一次。

## 用真实数据校准时的坑

- 领星 `ad_campaign_report` 的 `search_text` 不生效，按名称筛用 `name`；返回第一行是汇总行。
- 每个活动看 `top_of_search_impression_share`（搜索顶部展示份额），用它决定这个 CPC 属于哪一档。
- 判断“真实市场 CPC”只用固定竞价、出价没封顶的活动：先看活动 `bidding.strategy`（`autoForSales` = 提高和降低，`legacyForSales` = 只降低，`manual` = 固定）和出价 vs CPC。
- 只看广告表现好的时段时，按周挑，单日或 3 天、几单的高 CVR 不算数。
- 投放层的出价在 `ad_campaign_keyword_report`（关键词）和 `ad_campaign_targeting_report`（自动/商品投放，`adjustmentsBidMap` 有各位置实际出价）里；活动报告看不到。CPC ≥ 出价的 95% 就算封顶。
- 先问清这个产品的广告打法（守着打/推排名）：守着打时出价普遍封顶，CPC 只是下限，自然排名到一定位置就不动。
- 同期顺手查核心词自然排名：`get_asin_keyword_rank_trends`（每词 3 Credits，数据比当天晚 1–2 天），写进“CVR 与自然排名”表。
- 领星 `ad_campaign_report` 的 `portfolio_id` 是字符串，`ad_campaign_keyword_report`/`search_term_report` 的是数组。
