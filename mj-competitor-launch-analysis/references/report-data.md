# 报告数据格式（report.json）

网页由 `templates/report.html` 渲染，你只需要写一个 JSON 数据文件，再用 `scripts/build_report.py` 生成页面。完整示例见 `references/example-data.json`（DERACY B0FVSFPNCR）。

## 顶层字段

| 字段 | 说明 |
|---|---|
| `title` | 页面名称（浏览器标签和作品库里显示），写成“品牌 + 品类 + 首月复盘”，例如 `DERACY 健腹机首月复盘` |
| `heading` | 页面大标题，例如 `DERACY 健腹机 B0FVSFPNCR 上架首月复盘`；不填时用 `title` |
| `subtitle` | 一句话说明复盘口径，例如 D0 的取法。可选 |
| `meta` | 基础字段，二维数组 `[["站点","US"],["模式","上架首个30天"],["D0","2025-12-06"],["D+30","2026-01-05"],["截止日期","最新可用数据"]]`。每个字段单独一格，不要把两个字段写进一格 |
| `kpis` | 4 到 6 个关键指标卡片：`{"label","value","note"}`。建议：首月预估销量、D+30 评分数、首月广告流量占比、首月 BSR 最佳、当前子体月销量、核心词当前自然位 |
| `chart` | BSR 与售价走势图，见下文 |
| `sections` | 章节数组：`{"id","title","blocks":[...],"collapsed":false}` |
| `footer` | 页脚一句话，可选 |

## chart

```json
{
  "dates": ["2025-12-06", "..."],
  "bsr":   [null, 233750, "..."],
  "price": [57.99, "..."],
  "d0": "2025-12-06",
  "window": ["2025-12-06", "2026-01-05"],
  "windowLabel": "首月窗口",
  "events": [{"date": "2025-12-06", "label": "D0 低价开售 $57.99"}]
}
```

- `dates`、`bsr`、`price` 等长，按天排列，缺失值写 `null`。范围取 D0 前 3 天到广告时间线终点（首月模式是 D+60）。
- `events` 只放 4 到 8 个真正的运营节点（开售、涨价、降价、广告加码、Vine 集中上线、变体上线），图上按顺序编号。

## blocks 类型

| type | 字段 | 用途 |
|---|---|---|
| `conclusions` | `items` | 核心结论，带序号 |
| `text` | `text` | 一段话 |
| `list` | `title`（可选）、`items` | 要点列表 |
| `table` | `title`（可选）、`columns`、`rows`、`note`（可选）| 表格，**最多 6 列** |
| `weeks` | `weeks: [{label, range, rating, items:[[k,v]], verdict}]` | 按周时间轴卡片 |
| `callout` | `text` | 一句需要强调的提醒 |
| `chart` | — | 放走势图的位置（数据取顶层 `chart`）|

## 行内标记

- `**加粗**`
- `{推断:中}`、`{推断:高}`、`{推断:低}`：推断结论标签；`{无法确认}`：无法确认标签
- `{直接}`：直接数据标签，**只在核心结论里用**；其他地方默认就是直接数据，不标
- `{评级:强}`、`{评级:中}`、`{评级:弱}`、`{评级:负向}`、`{评级:无法判断}`：效果评级色块。表格单元格只写 `强` / `中` 等单字时也会自动变成色块
- 纯数字、金额、百分比、`#排名` 单元格会自动右对齐

## 写作规则

1. 基础字段每个单独一格；全文不用“/”连接两个概念，改用“和”“、”“或”或拆成两项。
2. 正文和标题都不写数据来源（卖家精灵、西柚、Keepa 等）。数据源分工只是取数约束。
3. 括号里不放次要细节（例如数据更新时间）。
4. 没有异常的章节和段落直接不写，也不写“按规则省略”。
5. 每节最多一张表，每张表最多 6 列；每节结论不超过三句。
6. 不写读者用不上的内部代号：广告活动 ID 写成“第 1 个 SP 活动”；SOR 等工具口径第一次出现时注明一次。
7. 总字数（不含图表数据）**上限 20,000 字**，按内容需要控制，生成脚本会提示。
