# 进类目前预估 CPC（mj-category-cpc）

2026-11-03 建立，2026-11-04 加入 WD1 并改为按顶部展示份额分档、增加同形态检查。用 AIRHOP 五个产品的真实广告数据校准：GF1（地垫，头部）、GF2（地垫，中部）、MH 头枕（Spa Beds & Tables 7792506011）、PB1 普拉提板（Pilates Reformers 13291011）、WD1 台式即热饮水机（Hot Water Dispensers 6810590011，混合需求词特例）、AB10 健腹机（Upper Body Machines 23533924011，成熟老品）。校准明细在 `references/calibration_2026-11-03.json`。

## 核心结论（用户确认过的口径）

- **西柚建议 CPC 不是市场成交价**。它按“净价 × 毛利率 × CVR”再按竞争难度往下压；转化率高、难度显示“简单”的类目会被低估（MH：真实 ＄5.0 vs 西柚 ＄2.7）。
- **西柚转化率 ≈ BSR 前 10 的平均转化率，当作头部产品的目标转化率**（用户判断，MH 类目用户估前 10 平均约 21%，西柚 20.4%；验证：GF1 1.1–1.3 倍、AB10 1.0–1.7 倍、MH 类目卖得最好的竞品约 0.9 倍，头部 ≈ 0.9–1.3 × C）。它是按点击加权的整词平均；ABA 里点击前 3 的 ASIN 往往低于它（吃了比价点击），但真正的头部产品能做到或超过它。
- **CVR 只看广告 CVR**（用户要求），不要用会话转化率。
- **CPC 取决于要拿多少搜索顶部展示份额（TOS）**，统一用 V 算：靠后位置（TOS <3%）≈ 0.22V（实测 0.17–0.24）；抢顶部（TOS 10–30%）≈ 0.40V（实测 0.36–0.45）；TOS 3–10% 取 0.25–0.35V。西柚定价正常的类目（西柚 CPC ≈ 0.22V，如 GF2）里，靠后约等于西柚建议价、抢顶部约 2 倍；西柚 CPC < 0.2V 时一律按 0.22V。
- **混合需求词要先剔掉异形态竞品**：主词下如果是饮水机、水槽下即热、保温壶这类不同形态的商品在投广告（WD1），P 和西柚 CPC 都会失真。只用同形态竞品算 P；同形态占广告流量很低时，靠后位置会比公式更便宜（WD1 hot water dispenser 实际 ＄0.81，公式 ＄1.46）。
- **动态竞价“提高和降低”在固定竞价市场价上再推高约 1.5 倍**（MH：同词固定竞价 ＄3.2–3.9 → 动态 ＄5.0）。“只降低”或出价太低时，实际 CPC 会被出价封顶（PB1），那不是市场价。

## 流程

0. **先确认入参**：计划售价、预计竞价策略（固定/只降低/提高和降低）、目标位置（靠后/抢顶部）。用户没说就按“固定竞价、靠后位置”算，并在结论里写明。
1. **定主词 3–5 个**：用户给，或从类目头部 ASIN 反查流量最大的词。剔掉明显不对口的词。
2. **拉数**（每词约 1 Credit；超过 3 次调用按全局规则交 `batch-offload` 的 `cb_pull.sh`/`oc_pull.sh`）：
   - `xydc-mcp get_keyword_info`：`keywords` 一次传完（≤100），拿 `clickConversionRate`、`costPerClick`、`competitiveDifficulty`、`abaReport.topAsins`。
   - `xydc-mcp get_keyword_asin_analysis`：每个主词一次，`page_size: 20`。
   - 可选 `sellersprite-mcp keyword_research` 看 PPC 竞价区间做旁证（卖家精灵每分钟限流，批量时会报 `ERROR_MAXIMUM_ACCESS_PER_MINUTE`，失败的单独补调）。
2b. **标同形态竞品**：Claude 读每个主词前 20 ASIN 的标题，挑出和我方形态、用途相同的 ASIN（不按价格判断），传给脚本 `--same`。所有词都是同形态时可以不传。
3. **跑脚本**：
   ```bash
   python3 -I ~/.claude/skills/mj-category-cpc/scripts/estimate_cpc.py \
     --info <get_keyword_info 返回>.json \
     --asin "主词1=<asin_analysis 返回1>.json" --asin "主词2=<返回2>.json" \
     --price <我方计划售价> [--cvr <预计广告CVR>] [--same ASIN1,ASIN2,...] --out result.json
   ```
4. **处理预警**：出现“词可能不对口”的词，从结论里剔除，必要时回第 1 步换词；高价大件污染时脚本已自动剔除 >2× 中位价的 ASIN 重算 P（输出里保留原值）。
5. **解读**（下面的公式和阈值）。分两段给 ACoS：**上架前期**按新品 CVR（0.3C）；**稳定后**按产品能做到的位置的 CVR（头部产品 C / 中部产品 0.6C）。交 Argon 挑刺（全局规则），再给用户结论。

## 公式

| 量 | 算法 |
|---|---|
| P | 词下前 20 ASIN **按广告流量加权**的价格（谁在出价就用谁的价格）；有异形态时只用同形态 ASIN |
| C | 西柚点击转化率 |
| **V（单次点击价值）** | P × C |
| 靠后位置 CPC（固定竞价，TOS <3%） | **0.22 × V**（区间 0.17–0.27） |
| 中间（TOS 3–10%） | 0.25–0.35 × V |
| 抢顶部 CPC（固定竞价 + 顶部溢价 30–50%，TOS 10–30%） | **0.40 × V** |
| 开“提高和降低” | × 1.5 |
| 我方预计广告 CVR | 稳定后：头部 ≈ C，中部 ≈ 0.6 × C；上架前期/评论少/评分低 ≈ 0.3 × C。用户给了就用用户的，但同时列出 0.3C 的前期结果（PB1 用户按 4.5% 算，实际最好两周 1.9%） |
| **预估 ACoS** | 预估 CPC ÷ (我方售价 × 我方预计 CVR) |

## 预警信号（脚本自动标）

| 信号 | 含义 |
|---|---|
| V ≥ ＄12 | 高 CPC 类目：竞品客单 × 转化率高，出得起价（MH ＄14.5） |
| 西柚 CPC < 0.2V | 西柚建议价低估，真实 CPC 会明显高于它（MH 0.18V） |
| 竞品广告加权价 ≥ 我方 1.4 倍 | 我方每次点击产出低，同样 CPC 下 ACoS 高（MH 1.5 倍） |
| 竞品广告加权价 ≥ 我方 2 倍 | 词下多是更贵的大件，词不对口（pilates reformer 3.8 倍） |
| 高价（>2× 中位价）ASIN 占广告流量 ≥30% | 西柚 CPC 被大件拉高，先剔除再看（没传 `--same` 时脚本自动剔除） |
| 同形态竞品占广告流量 <35% | 混合需求词：西柚 CPC 偏高（WD1 是实际的 3–4 倍）；同形态没人投时靠后位置很便宜 |

## 局限（结论里要写）

- 样本 6 个产品；靠后档 0.22 有 GF2、WD1、AB10 三个成熟老品支撑，新品在靠后位置是否同样便宜还没验证；抢顶部系数 0.4 只有 GF1 一个干净的点（MH 是动态竞价）。WD1 是混合需求词特例，不当通用校准点。新类目跑完、有真实数据后，把实际 CPC/V 补进校准表，更新系数和回测表。
- 复购型、品牌防守型类目，竞品按长期价值出价，系数会偏高。
- 大促期间 CPC 整体上浮；拉数避开大促周。
- 西柚数据抓的是最近一周；季节品要看旺季前后再拉一次。

## 用真实数据校准时的坑

- 领星 `ad_campaign_report` 的 `search_text` 不生效，按名称筛用 `name`；返回第一行是汇总行。
- 每个活动看 `top_of_search_impression_share`（搜索顶部展示份额），用它决定这个 CPC 属于哪一档。
- 判断“真实市场 CPC”只用固定竞价、出价没封顶的活动：先看活动 `bidding.strategy`（`autoForSales` = 提高和降低，`legacyForSales` = 只降低，`manual` = 固定）和出价 vs CPC。
- 只看广告表现好的时段时，按周挑，单日或 3 天、几单的高 CVR 不算数。
